# Раздел 1. Дискретная математика и математическое моделирование

## 1.1. Алгебра множеств. Конечные и бесконечные множества. Кантор–Бернштейн. Уравнения с множествами

### Пять пунктов для запоминания

1. Множества объединяют, пересекают, вычитают и дополняют.
2. Размер сравнивают биекцией, а не обычным подсчётом.
3. Бесконечности бывают счётными и несчётными.
4. Две инъекции в разные стороны дают биекцию.
5. Уравнение с множествами решают отдельно для каждого элемента.

### Что написать на листе

1. **Операции:** `A∪B` — хотя бы в одном; `A∩B` — в обоих; `A\B` — в A, но не в B; `Ā=U\A`; `A△B` — ровно в одном. Де Морган: `overline(A∪B)=Ā∩B̄`, `overline(A∩B)=Ā∪B̄`.
2. **Мощность:** `|A|=|B|` тогда и только тогда, когда существует биекция `A↔B`. Инъекция не склеивает элементы, сюръекция покрывает весь кодомен.
3. **Виды множеств:** конечное равномощно `{1,…,n}`; счётно бесконечное — `ℕ`. Примеры: `ℤ,ℚ` счётны, `ℝ` несчётно; `|ℕ|<|ℝ|`.
4. **Кантор–Бернштейн:** если существуют инъекции `f:A→B` и `g:B→A`, то существует биекция `A↔B`. Идея — разбиение элементов на цепочки.
5. **Уравнение:** `A∩X=B` имеет решения только при `B⊆A`; общее решение `X=B∪Y`, где произвольное `Y⊆U\A`.

### Говорить

Множество — это совокупность объектов, называемых элементами. Все множества будем рассматривать внутри универсума `U`. Объединение `A∪B` содержит элементы хотя бы одного множества, пересечение `A∩B` — элементы сразу обоих, разность `A\B` — элементы A, отсутствующие в B. Дополнение `Ā` состоит из элементов универсума, не входящих в A. Симметрическая разность `A△B` содержит элементы, входящие ровно в одно множество. Эти операции подчиняются законам булевой алгебры, в частности законам де Моргана: дополнение объединения равно пересечению дополнений, а дополнение пересечения — объединению дополнений.

Размер множества называют мощностью. Множества равномощны, если между ними существует биекция, то есть соответствие один к одному без пропусков. Конечное множество равномощно `{1,…,n}` для некоторого n. Бесконечное множество конечным не является и может быть равномощно собственной части. Например, `n↦2n` задаёт биекцию натуральных чисел с чётными.

Счётно бесконечное множество равномощно `ℕ`. Целые и рациональные числа счётны: их можно расположить в последовательность. Действительные числа несчётны. Кантор доказал это диагональным методом: для любого предполагаемого списка дробей можно построить новую дробь, отличающуюся от n-й строки в n-м знаке. Поэтому `|ℕ|<|ℝ|`.

Теорема Кантора–Бернштейна утверждает: если есть инъекция `A→B` и инъекция `B→A`, то существует биекция `A↔B`. Практический смысл в том, что две инъекции часто построить проще, чем явную биекцию.

Уравнения с множествами решают поэлементно или через характеристические функции. Например, `A∩X=B` разрешимо только при `B⊆A`. В X обязательно входят элементы B, не входят элементы `A\B`, а элементы вне A выбираются свободно. Поэтому все решения имеют вид `X=B∪Y`, где `Y⊆U\A`.

## 1.2. Алгебра логики. Жегалкин. СДНФ и СКНФ. Теорема Поста

### Пять пунктов для запоминания

1. Булева функция работает с нулями и единицами.
2. СДНФ собирается по единичным строкам таблицы.
3. СКНФ собирается по нулевым строкам таблицы.
4. Полином Жегалкина использует `⊕`, умножение и единицу.
5. Для полноты по Посту нужен минус в каждом из пяти классов.

### Что написать на листе

1. **Операции:** `¬` — НЕ, `∧` — И, `∨` — неисключающее ИЛИ, `⊕` — ровно одно. Булева функция: `f:{0,1}ⁿ→{0,1}`.
2. **СДНФ:** взять строки `f=1`, для каждой составить конъюнкцию всех переменных, затем соединить через `∨`. Пример XOR: `(¬x∧y)∨(x∧¬y)`.
3. **СКНФ:** взять строки `f=0`, построить дизъюнкции, ложные на этих строках, затем соединить их через `∧`.
4. **Жегалкин:** любая функция единственно представима полиномом из `⊕`, умножения и 1; `¬x=1⊕x`, `1⊕1=0`.
5. **Пост:** классы `T₀,T₁,S,M,L`. Система полна тогда и только тогда, когда не содержится целиком ни в одном классе; в каждом столбце таблицы должен быть минус.

### Говорить

Алгебра логики работает со значениями 0 и 1, то есть ложью и истиной. Отрицание `¬x` меняет значение, конъюнкция `x∧y` истинна только при двух единицах, дизъюнкция `x∨y` — когда истинен хотя бы один аргумент, включая случай двух единиц. Исключающее ИЛИ `x⊕y` истинно ровно при разных значениях. Булева функция сопоставляет каждому набору нулей и единиц один ответ 0 или 1 и полностью задаётся таблицей истинности.

Совершенные нормальные формы позволяют механически построить формулу по таблице. СДНФ строится по строкам, где функция равна единице. Для каждой строки составляется конъюнкция всех переменных, с отрицанием тех, которые в строке равны нулю, затем конъюнкции соединяются дизъюнкцией. СКНФ строится по нулевым строкам: создаются дизъюнкции, ложные на соответствующей строке, и соединяются конъюнкцией. Например, XOR имеет СДНФ `(¬x∧y)∨(x∧¬y)`.

В алгебре Жегалкина используются сложение по модулю два `⊕`, умножение и единица. Для сложения `1⊕1=0`. Любая булева функция единственным образом представима полиномом Жегалкина. Например, отрицание равно `1⊕x`, а XOR — `x⊕y`.

Теорема Поста отвечает, можно ли из данного набора функций выразить любую булеву функцию. Рассматриваются пять замкнутых классов: сохраняющие ноль `T₀`, сохраняющие единицу `T₁`, самодвойственные `S`, монотонные `M` и линейные `L`. Система функционально полна тогда и только тогда, когда она не содержится целиком ни в одном из этих классов. На практике строят таблицу Поста: система полна, если в каждом из пяти столбцов имеется хотя бы один минус.

## 1.3. Линейные модели и симплекс-метод

### Пять пунктов для запоминания

1. Переменные описывают план, цель — прибыль или затраты.
2. Ограничения образуют допустимый многогранник.
3. Конечный линейный оптимум достигается в вершине.
4. Симплекс переходит между соседними базисными вершинами.
5. Итогом может быть оптимум, несовместность или неограниченность.

### Что написать на листе

1. **Модель:** `cᵀx→max`, `Ax≤b`, `x≥0`; x — план, c — прибыль, A — расходы ресурсов, b — запасы.
2. **Допустимость:** решение удовлетворяет ограничениям; допустимое множество — выпуклый многогранник.
3. **Основная теорема:** если конечный оптимум существует, он достигается хотя бы в одной вершине; вершина соответствует базисному допустимому решению.
4. **Итерация:** выбрать входящую переменную по приведённой стоимости, выходящую — по минимальному отношению; пересчитать базис.
5. **Окончание:** все оценки нужного знака — оптимум; нет ограничивающей строки — неограниченность; первая фаза выявляет несовместность.

### Говорить

Линейная оптимизационная модель описывает ситуацию, где переменные, ограничения и целевая функция линейны. Например, `x₁` и `x₂` могут означать количество двух изделий, `cᵀx` — прибыль, а `Ax≤b` — ограничения ресурсов. Допустимым называется решение, удовлетворяющее всем ограничениям, а оптимальным — допустимое решение с лучшим значением цели.

Геометрически ограничения задают выпуклый многогранник. Если конечный оптимум существует, линейная функция достигает его хотя бы в одной вершине. В канонической форме неравенства превращают в равенства с помощью добавочных переменных. Вершине соответствует базисное допустимое решение: часть переменных выбирают базисными и находят из системы, остальные полагают равными нулю.

Симплекс-метод начинает с базисного допустимого решения и переходит по соседним вершинам, улучшая целевую функцию. По приведённым стоимостям выбирается переменная, которая войдёт в базис. По минимальному отношению выбирается переменная, которая выйдет, чтобы не нарушить неотрицательность. Затем таблицу пересчитывают методом Жордана–Гаусса.

Если улучшить цель больше нельзя, текущая вершина оптимальна. Если для выбранного направления нет ограничивающей строки, цель не ограничена. Первая фаза метода обнаруживает отсутствие допустимых решений. Возможны также несколько оптимумов и вырожденность. В худшем случае симплекс экспоненциален, но на практике часто эффективен; полиномиальная альтернатива — методы внутренней точки.

## 1.4. Рюкзак, коммивояжёр и назначения

### Пять пунктов для запоминания

1. Переборные задачи выбирают ответ из множества комбинаций.
2. Рюкзак выбирает предметы при ограниченной вместимости.
3. Коммивояжёр ищет кратчайший цикл через все города.
4. Назначения распределяют исполнителей по работам.
5. Рюкзак и TSP трудны, назначения решаются за `O(n³)`.

### Что написать на листе

1. **Общее:** решение выбирается из конечного множества комбинаций; полный перебор растёт экспоненциально или факториально.
2. **Рюкзак:** `max Σv_ix_i`, `Σw_ix_i≤W`, `x_i∈{0,1}`. Полный перебор `2ⁿ`, ДП `O(nW)`.
3. **Дробный рюкзак:** предметы делимы; жадно сортируем по `v_i/w_i`, сложность `O(n log n)`.
4. **Коммивояжёр:** гамильтонов цикл минимального веса; перебор `O(n!)`, ДП Хелда–Карпа `O(n²2ⁿ)`.
5. **Назначения:** `min Σc_ijx_ij`, каждому исполнителю одна работа; венгерский алгоритм `O(n³)`, задача полиномиальна.

### Говорить

Переборными называют задачи, где решение выбирают из конечного, но очень большого множества комбинаций. В задаче о рюкзаке каждый предмет имеет вес и ценность. Переменная `x_i` равна единице, если предмет взят. Максимизируется суммарная ценность при ограничении общей массы. Полный перебор требует до `2ⁿ` вариантов. Динамическое программирование по предметам и вместимости работает за `O(nW)`, но эта оценка псевдополиномиальна, потому что зависит от численного значения W. Дробный рюкзак, где предмет можно делить, решается жадно по отношению ценности к весу.

В задаче коммивояжёра нужно посетить каждый город ровно один раз, вернуться в начало и минимизировать длину маршрута. Это поиск гамильтонова цикла минимального веса. Полный перебор имеет порядок `n!`, динамическое программирование Хелда–Карпа — `O(n²2ⁿ)`. Также применяют ветви и границы, приближённые алгоритмы и эвристики.

В задаче назначений каждый исполнитель получает одну работу, и каждая работа — одного исполнителя. Минимизируется сумма стоимостей `c_ij`. Несмотря на переборную формулировку, специальная структура позволяет решить её венгерским алгоритмом за `O(n³)`.

Главный вывод: похожие дискретные задачи могут иметь разную сложность. Нужно различать точный алгоритм, приближённый алгоритм с гарантией и эвристику без общей гарантии оптимальности.

## 1.5. Графы, Эйлер, Гамильтон, деревья, планарность и раскраска

### Пять пунктов для запоминания

1. Граф — вершины и соединяющие их рёбра.
2. Эйлер проходит все рёбра, Гамильтон — все вершины.
3. Дерево связно, не имеет циклов и содержит `n−1` ребро.
4. Планарный граф можно уложить без пересечений.
5. На графах ищут пути, остовы, потоки и раскраски.

### Что написать на листе

1. **Определения:** `G=(V,E)`; степень — число рёбер вершины; путь — последовательность соседних вершин; цикл возвращается в начало; связность — наличие пути.
2. **Эйлер:** пройти каждое ребро один раз. Цикл существует ⇔ граф связен и все степени чётны; путь — при 0 или 2 нечётных вершинах.
3. **Гамильтон:** посетить каждую вершину один раз. Простого общего критерия нет; не путать с Эйлером.
4. **Дерево и планарность:** дерево связно и ациклично, имеет `n−1` ребро; код Прюфера длины `n−2`. Для плоского графа `V−E+F=2`, цветов достаточно четырёх.
5. **Алгоритмы:** Дейкстра — кратчайший путь; Краскал/Прим — минимальный остов; максимальный поток равен минимальному разрезу.

### Говорить

Граф `G=(V,E)` состоит из множества вершин и множества рёбер, соединяющих вершины. Степень вершины — число инцидентных ей рёбер. Путь — последовательность соседних вершин, цикл возвращается в начало, связный граф допускает путь между любыми двумя вершинами.

Эйлеров путь проходит по каждому ребру ровно один раз. Связный неориентированный граф имеет эйлеров цикл тогда и только тогда, когда степени всех вершин чётны. Эйлеров путь без возврата существует при ровно двух нечётных вершинах. Гамильтонов путь, напротив, посещает каждую вершину ровно один раз. Простого необходимого и достаточного критерия гамильтоновости нет, и задача существенно труднее. Запоминалка: Эйлер следит за рёбрами, Гамильтон — за вершинами.

Дерево — связный граф без циклов. У дерева с n вершинами `n−1` ребро, и между любыми двумя вершинами существует единственный путь. Код Прюфера задаёт помеченное дерево последовательностью длины `n−2`; отсюда число помеченных деревьев равно `n^(n−2)`.

Планарный граф можно нарисовать без пересечений рёбер. Для связного плоского графа выполняется формула Эйлера `V−E+F=2`, откуда следует необходимая оценка `E≤3V−6`. Любой планарный граф можно правильно раскрасить не более чем четырьмя цветами.

Типовые оптимизационные задачи на графах: кратчайший путь — алгоритм Дейкстры при неотрицательных весах; минимальное остовное дерево — алгоритмы Краскала и Прима; максимальный поток — потоковые алгоритмы и теорема о равенстве максимального потока минимальному разрезу.

## 1.6. Условия Куна–Таккера

### Пять пунктов для запоминания

1. ККТ проверяют оптимум задачи с ограничениями.
2. Негладкий градиент заменяется субдифференциалом.
3. Лагранжиан объединяет цель и ограничения.
4. Неактивное ограничение имеет нулевой множитель.
5. При выпуклости и Слейтере ККТ необходимы и достаточны.

### Что написать на листе

1. **Задача:** `f(x)→min`, `g_i(x)≤0`, `h_j(x)=0`; функции выпуклые, но могут быть негладкими.
2. **Негладкость:** вместо градиента используется субдифференциал `∂f(x)` — множество опорных наклонов.
3. **Лагранжиан:** `L=f+Σλ_ig_i+Σμ_jh_j`; множители λ — теневые цены ограничений.
4. **ККТ:** исходная допустимость; `λ_i≥0`; стационарность `0∈∂_xL`; дополняющая нежёсткость `λ_ig_i(x*)=0`.
5. **Теорема:** при выпуклости и условии Слейтера ККТ необходимы и достаточны; без выпуклости обычно только необходимы.

### Говорить

Рассматривается задача минимизации функции `f(x)` при ограничениях-неравенствах `g_i(x)≤0` и равенствах `h_j(x)=0`. Выпуклость означает, что отрезок между допустимыми точками остаётся допустимым, а функция имеет форму без ложных локальных минимумов. Негладкая функция может иметь угол, поэтому вместо единственного градиента используют субдифференциал — множество допустимых наклонов.

Строится лагранжиан `L=f+Σλ_ig_i+Σμ_jh_j`. Условия Куна–Таккера включают четыре части. Первая — исходная допустимость ограничений. Вторая — двойственная допустимость `λ_i≥0`. Третья — стационарность: ноль принадлежит сумме субдифференциалов цели и ограничений с соответствующими множителями. Четвёртая — дополняющая нежёсткость `λ_ig_i(x*)=0`.

Последнее условие означает: если ограничение не активно, его множитель равен нулю; положительная теневая цена возможна только для ограничения, достигшего границы. Множители можно интерпретировать как чувствительность оптимального значения к запасам ресурсов.

При выпуклости и условии регулярности Слейтера, то есть существовании точки, строго выполняющей неравенства, условия ККТ необходимы и достаточны. В невыпуклой задаче они обычно только необходимы и сами по себе не гарантируют глобальный минимум.

## 1.7. Принцип максимума Понтрягина

### Пять пунктов для запоминания

1. Управление выбирается как функция времени.
2. Состояние движется по уравнению `ẋ=f(x,u,t)`.
3. Сопряжённая переменная выражает будущую цену состояния.
4. Оптимальное управление максимизирует гамильтониан.
5. Принцип даёт необходимые, но не всегда достаточные условия.

### Что написать на листе

1. **Постановка:** состояние `x(t)`, управление `u(t)∈U`, динамика `ẋ=f(x,u,t)`, интегральный и конечный критерий J.
2. **Гамильтониан:** `H=pᵀf−L`; p — сопряжённая переменная, то есть будущая цена изменения состояния.
3. **Каноническая система:** `ẋ=∂H/∂p`, `ṗ=−∂H/∂x` плюс начальные и конечные условия.
4. **Условие максимума:** `u*(t)∈argmax_{u∈U}H(p,x*,u,t)` почти всюду; на конце выполняется трансверсальность.
5. **Смысл:** принцип даёт необходимых кандидатов, но без дополнительных условий не гарантирует глобальный оптимум.

### Говорить

В оптимальном управлении выбирается не одна точка, а функция управления `u(t)`, влияющая на состояние `x(t)` через уравнение `ẋ=f(x,u,t)`. Требуется минимизировать или максимизировать функционал, оценивающий затраты вдоль всей траектории и конечный результат.

Для записи необходимых условий вводят сопряжённую переменную `p(t)`, которую можно понимать как будущую цену изменения состояния, и гамильтониан. При принятом соглашении он имеет вид `H=pᵀf−L`, где L — текущие затраты.

Если управление оптимально, то состояние удовлетворяет исходной системе, сопряжённая переменная — уравнению `ṗ=−∂H/∂x`, выполняются граничные условия и условия трансверсальности, а управление `u*(t)` почти в каждый момент максимизирует гамильтониан по допустимому множеству управлений.

Например, если гамильтониан линейно зависит от ограниченного управления, максимум часто достигается на границе: получается релейное управление типа «полная тяга или выключение». Полученная система является краевой: часть условий задана в начале, часть в конце, поэтому её решают методом стрельбы или прямой дискретизацией.

Важно подчеркнуть, что принцип максимума даёт необходимые условия. Кандидат, удовлетворяющий им, ещё не обязательно является глобально оптимальным без дополнительных условий выпуклости.

## 1.8. Гарантированный результат, минимакс и оптимальный поиск

### Пять пунктов для запоминания

1. Гарантия оценивает решение по худшему допустимому случаю.
2. Для потерь используется принцип `min max`.
3. Равенство максимина и минимакса даёт седловую точку.
4. Смешанные стратегии гарантируют цену матричной игры.
5. Фибоначчи оптимален по худшей ошибке при заданном числе проб.

### Что написать на листе

1. **Неопределённость:** x выбираем мы, y — природа или противник; оцениваем худший допустимый исход.
2. **Потери:** `min_x max_y F(x,y)`; **выигрыш:** `max_x min_y F(x,y)`.
3. **Цены игры:** `max min≤min max`; равенство означает седловую точку и цену игры.
4. **Матричная игра:** в смешанных стратегиях теорема фон Неймана гарантирует равенство максимина и минимакса.
5. **Поиск:** золотое сечение повторно использует точку; метод Фибоначчи минимизирует худшую длину интервала при заданном числе вычислений.

### Говорить

Принцип наилучшего гарантированного результата применяется, когда часть условий неизвестна или выбирается противником. Если `F(x,y)` — потери, мы выбираем x, предполагая худшее y, и решаем `min_x max_y F(x,y)`. Сначала для каждого решения определяем его худшую потерю, затем выбираем решение с наименьшей из этих потерь.

В игровой постановке различают максимин и минимакс. Всегда нижняя цена игры не превосходит верхнюю. Если они совпадают, существует седловая точка и цена игры. В конечной антагонистической игре равенство достигается в смешанных стратегиях по теореме фон Неймана.

Та же идея худшего случая используется при сравнении алгоритмов поиска экстремума. Для унимодальной функции на отрезке требуется после заданного числа измерений получить как можно меньший гарантированный интервал неопределённости. Метод золотого сечения размещает точки так, чтобы на следующем шаге повторно использовать одно вычисленное значение. Метод Фибоначчи при заранее известном числе измерений является оптимальным в минимаксном смысле.

Таким образом, наилучший гарантированный результат — это не обещание хорошего среднего исхода, а строгая защита от самого неблагоприятного допустимого случая.

## 1.9. Метод штрафных функций

### Пять пунктов для запоминания

1. Нарушение ограничения добавляет стоимость к цели.
2. Внешний штраф допускает временный выход из области.
3. Барьер удерживает точки строго внутри области.
4. Коэффициент штрафа увеличивают постепенно.
5. Слишком большой коэффициент ухудшает обусловленность.

### Что написать на листе

1. **Исходная задача:** `f(x)→min` при `g_i(x)≤0`; ограничения заменяются добавкой к цели.
2. **Внешний штраф:** `F_r=f+rΣmax(0,g_i)²`; вне области штраф положителен, `r_k→∞`.
3. **Барьер:** `f−μΣln(−g_i)` определён внутри области и не позволяет пересечь границу.
4. **Схема:** решить серию безусловных задач, повышая штраф и используя предыдущее решение как начальное.
5. **Проблема:** большой r улучшает допустимость, но ухудшает обусловленность; точный штраф может работать при конечном r.

### Говорить

Метод штрафных функций заменяет задачу с ограничениями последовательностью задач без ограничений. К исходной целевой функции добавляется величина, равная нулю на допустимых точках и положительная при нарушении. Например, `F_r(x)=f(x)+rΣmax(0,g_i(x))²`.

При небольшом r оптимизатор может нарушать ограничения ради улучшения исходной цели. Затем r увеличивают, каждый новый запуск начиная с предыдущего решения. При подходящих условиях предельные точки приближаются к решению исходной задачи.

Внешний штраф разрешает промежуточным точкам находиться вне допустимой области. Внутренняя барьерная функция, например `−μΣlog(−g_i(x))`, определена только внутри и стремится к бесконечности около границы. Точные негладкие штрафы могут дать точное решение уже при конечном коэффициенте.

Главная численная проблема состоит в том, что слишком большой штраф делает поверхность очень крутой поперёк ограничений и плоской вдоль них. Задача становится плохо обусловленной. Поэтому коэффициент повышают постепенно и применяют тёплый старт; более устойчивой альтернативой служит расширенный лагранжиан.

## 1.10. Динамическое программирование и принцип Беллмана

### Пять пунктов для запоминания

1. Задача разбивается на состояния и этапы.
2. Хвост оптимальной стратегии сам оптимален.
3. Уравнение Беллмана выбирает лучший первый ход и продолжение.
4. Обратный ход считает значения, прямой восстанавливает стратегию.
5. Главная проблема — взрыв числа состояний.

### Что написать на листе

1. **Элементы:** этап k, состояние s, управление u, переход `T(s,u)`, награда `r(s,u)`.
2. **Принцип:** хвост оптимальной стратегии оптимален для состояния, возникшего после первых шагов.
3. **Уравнение:** `V_k(s)=max_u{r(s,u)+V_(k+1)(T(s,u))}` с терминальным условием.
4. **Логика:** оптимальность хвоста необходима; стратегия, всегда выбирающая `argmax` уравнения, достаточна для оптимальности.
5. **Алгоритм:** обратный ход заполняет V, прямой восстанавливает решения; ограничение — проклятие размерности.

### Говорить

Динамическое программирование применяется к многоэтапным задачам. Состояние должно содержать всю информацию, необходимую для будущих решений. Управление выбирается на каждом этапе, переводит систему в новое состояние и приносит выигрыш или затраты.

Принцип оптимальности Беллмана утверждает: хвост оптимальной стратегии должен быть оптимальным для состояния, возникшего после предыдущих решений. Если бы хвост был хуже другого, его можно было бы заменить и улучшить всю стратегию.

Пусть `V_k(s)` — лучший результат с этапа k из состояния s. Тогда уравнение Беллмана имеет вид `V_k(s)=max_u{r(s,u)+V_{k+1}(T(s,u))}`. Оно перебирает первый ход, складывает немедленную награду с уже известным лучшим продолжением.

Необходимость состоит в оптимальности каждого хвоста. Достаточность формулируется так: если функция удовлетворяет уравнению Беллмана и стратегия на каждом шаге выбирает действие, достигающее максимума, то эта стратегия оптимальна.

Вычисление идёт обратным ходом от последнего этапа к первому, затем прямым ходом восстанавливается траектория. Примеры — рюкзак, кратчайший путь и распределение ресурсов. Ограничение метода — проклятие размерности: число состояний быстро растёт с числом параметров.

## 1.11. Персептрон, автоматы и марковские модели поведения

### Пять пунктов для запоминания

1. Обучение — изменение состояния под действием опыта.
2. Персептрон корректирует веса только при ошибке.
3. Сходимость гарантируется для линейно разделимых данных.
4. Марковское будущее зависит только от текущего состояния.
5. В играх исследуют стратегии, равновесия и сходимость поведения.

### Что написать на листе

1. **Общая идея:** обучение и поведение — динамика состояния под действием опыта и обратной связи.
2. **Персептрон:** `ŷ=sign(wᵀx+b)`; при ошибке `w←w+ηdx`. При линейной разделимости число ошибок конечно.
3. **Автомат:** конечные состояния, действия, поощрение и штраф; переходы постепенно закрепляют выгодное действие.
4. **Марковская модель:** будущее зависит только от текущего; матрица P, стационарность `π=πP`; в MDP добавляются действия и награды.
5. **Игры:** стратегия и выигрыш; минимакс для антагонистической игры, равновесие Нэша — отсутствие выгодного одностороннего отклонения.

### Говорить

Общая идея вопроса состоит в том, что обучение и поведение можно рассматривать как динамическую систему: имеется состояние, правило его изменения и критерий качества.

Персептрон — линейный классификатор `ŷ=sign(wᵀx+b)`. Вектор весов задаёт разделяющую гиперплоскость. Для меток `−1` и `+1` при ошибке веса корректируются по правилу `w←w+ηdx`, а при правильном ответе не меняются. Поэтому обучение является дискретной траекторией в пространстве весов. Если выборка линейно разделима с положительным зазором, теорема сходимости гарантирует конечное число ошибок. Однослойный персептрон не решает линейно неразделимую задачу XOR.

Обучающийся автомат имеет конечное число внутренних состояний, выбирает действие и получает поощрение или штраф от среды. Переходы усиливают успешное действие или приближают смену неудачного. При увеличении глубины памяти автомат Цетлина ведёт себя асимптотически оптимально в стационарной случайной среде.

В цепи Маркова вероятность следующего состояния зависит только от текущего. Матрица P содержит вероятности переходов, а стационарное распределение удовлетворяет `π=πP`. В марковском процессе принятия решений добавляются действия и награды; оптимальная политика находится уравнением Беллмана. Во всех трёх моделях основной исследовательский вопрос один: сходится ли процесс и становится ли поведение оптимальным.

В игровой модели несколько участников выбирают стратегии, а выигрыш каждого зависит от совместного выбора. Для антагонистической игры используется минимакс и смешанные стратегии. В неантагонистической игре важным понятием является равновесие Нэша: ни одному игроку невыгодно одному менять стратегию. Повторяющиеся игры и обучение по накопленному выигрышу снова задают динамическую систему поведения.

# Раздел 2. Численные методы и методы оптимизации

## 2.1. Интерполяция и аппроксимация

### Пять пунктов для запоминания

1. Интерполяция точно проходит через заданные точки.
2. Высокий полином может колебаться, поэтому применяют сплайны.
3. МНК минимизирует сумму квадратов отклонений.
4. Равномерное приближение уменьшает максимальную ошибку.
5. В гильбертовом пространстве лучший ответ — ортогональная проекция.

### Что написать на листе

1. **Интерполяция:** по узлам `(x_i,y_i)` найти `P(x_i)=y_i`; полином степени ≤n существует и единственен. Формы Лагранжа и Ньютона.
2. **Ошибка:** `f−P=f^(n+1)(ξ)·Π(x−x_i)/(n+1)!`; равномерные узлы высокой степени могут давать феномен Рунге.
3. **Сплайн:** кусочно-кубическая функция, непрерывны S, `S'`, `S''`; локальность и устойчивость, типичная ошибка `O(h⁴)`.
4. **МНК:** `min Σ(y_i−φ(x_i))²`; для линейной модели `AᵀAc=Aᵀy`, практически QR/SVD устойчивее.
5. **Лучшие приближения:** равномерное минимизирует `max|f−p|`; в гильбертовом пространстве ответ — ортогональная проекция, невязка ортогональна подпространству.

### Говорить

Интерполяция и аппроксимация восстанавливают зависимость по данным, но ставят разные требования. Интерполяция обязана точно пройти через все узлы: `P(x_i)=y_i`. Для различных узлов существует единственный полином степени не выше n. В форме Лагранжа он является суммой значений `y_i`, умноженных на базисные полиномы, которые равны единице в своём узле и нулю в остальных. Форма Ньютона использует разделённые разности и удобна при добавлении узлов.

Ошибка полиномиальной интерполяции зависит от производной порядка `n+1` и произведения `(x−x_i)`. На равномерной сетке высокая степень может вызвать колебания Рунге. Поэтому применяют сплайны: на каждом малом интервале строится кубический полином, а куски соединяются с непрерывными первой и второй производными.

Аппроксимация допускает ошибки в точках. Метод наименьших квадратов минимизирует сумму квадратов отклонений. Для линейной модели получаются нормальные уравнения `AᵀAc=Aᵀy`, хотя численно предпочтительнее QR или SVD.

Наилучшее равномерное приближение минимизирует максимальную ошибку. Для полиномов его характеризует теорема Чебышёва об альтернансе. В гильбертовом пространстве лучшим приближением из подпространства является ортогональная проекция: ошибка ортогональна всем базисным направлениям. Таким образом, интерполяция отвечает за точное совпадение, а виды аппроксимации различаются выбранной мерой ошибки.

## 2.2. Численное дифференцирование

### Пять пунктов для запоминания

1. Производная заменяется отношением конечных разностей.
2. Односторонняя формула обычно имеет порядок один.
3. Центральная формула благодаря симметрии имеет порядок два.
4. Малый шаг уменьшает усечение, но усиливает округление.
5. Шумные данные сначала нужно сгладить.

### Что написать на листе

1. **Идея:** заменить производную производной интерполяционного полинома или вывести формулу разложением Тейлора.
2. **Первая производная:** правая разность `[f(x+h)−f(x)]/h`, ошибка `O(h)`; обратная строится аналогично.
3. **Центральные формулы:** `f'≈[f(x+h)−f(x−h)]/(2h)`, `O(h²)`; `f''≈[f(x+h)−2f(x)+f(x−h)]/h²`, `O(h²)`.
4. **Порядок:** ошибка аппроксимации `C₁h^p`; уменьшение h вдвое уменьшает её примерно в `2^p` раз.
5. **Общая ошибка:** примерно `C₁h^p+C₂ε/h`; слишком малый шаг усиливает округление и шум, поэтому данные сглаживают и выбирают оптимальный h.

### Говорить

Численное дифференцирование приближённо вычисляет производные по значениям функции в узлах. Формулы получают из разложения Тейлора или дифференцированием интерполяционного полинома.

Правая разность `[f(x+h)−f(x)]/h` приближает первую производную с ошибкой порядка `O(h)`. Центральная разность `[f(x+h)−f(x−h)]/(2h)` использует симметрию, уничтожающую первый ошибочный член, и имеет порядок `O(h²)`. Вторая производная приближается выражением `[f(x+h)−2f(x)+f(x−h)]/h²` также со вторым порядком.

Порядок p означает, что при уменьшении шага вдвое ошибка аппроксимации примерно уменьшается в `2^p` раз. Однако брать h сколь угодно малым нельзя. В числителе вычитаются близкие машинные числа, возникает потеря значащих цифр, а ошибка округления делится на h. Общая ошибка имеет вид суммы `C₁h^p` и примерно `C₂ε/h`, поэтому существует оптимальный ненулевой шаг.

Дифференцирование также усиливает шум экспериментальных данных. В таком случае сначала строят сглаживающую аппроксимацию или применяют регуляризацию, а затем дифференцируют полученную функцию.

## 2.3. Численное интегрирование

### Пять пунктов для запоминания

1. Интеграл заменяется взвешенной суммой значений.
2. Ньютона–Котеса использует равноотстоящие узлы.
3. Составная формула работает на многих малых отрезках.
4. Трапеция имеет порядок два, Симпсон — четыре.
5. Гаусс с n узлами точен до степени `2n−1`.

### Что написать на листе

1. **Квадратура:** `∫_a^b f(x)dx≈ΣA_if(x_i)`; узлы `x_i`, веса `A_i`; вывод через интегрирование интерполяционного полинома.
2. **Ньютона–Котеса:** равноотстоящие узлы; прямоугольники, трапеция, Симпсон.
3. **Составные формулы:** интервал разбивается на шаг h; глобальная ошибка трапеции `O(h²)`, Симпсона `O(h⁴)`.
4. **Точность:** алгебраическая степень — наибольшая степень полинома, интегрируемого точно; остаток зависит от производной функции.
5. **Гаусс:** выбираются и веса, и узлы; n узлов обеспечивают точность для степеней до `2n−1`; адаптивная схема дробит сложные участки.

### Говорить

Численное интегрирование заменяет интеграл конечной взвешенной суммой значений функции: `∫_a^b f(x)dx≈ΣA_if(x_i)`. Точки `x_i` называются узлами, числа `A_i` — весами. Интерполяционные квадратуры получают, заменяя функцию интерполяционным полиномом и точно интегрируя этот полином.

Формулы Ньютона–Котеса используют равноотстоящие узлы. Интерполяция константой даёт прямоугольники, прямой — трапецию, параболой через три точки — формулу Симпсона. Для большого интервала применяют составные правила: разбивают его на малые части и суммируют результаты. Составная трапеция имеет ошибку `O(h²)`, Симпсон — `O(h⁴)` при достаточной гладкости.

Алгебраическая степень точности — максимальная степень полинома, для которого формула точна. Если разрешить выбирать не только веса, но и узлы, получаются квадратуры Гаусса. Формула с n узлами Гаусса точна для полиномов степени до `2n−1`, что является наивысшей возможной степенью.

На практике ошибку оценивают сравнением результатов на грубой и более мелкой сетках. Адаптивный алгоритм дробит только участки, где оценка ошибки велика. Отдельной обработки требуют разрывы, особенности и быстро осциллирующие функции.

## 2.4. Итерационные методы линейной алгебры

### Пять пунктов для запоминания

1. Итерация последовательно улучшает решение `Ax=b`.
2. Невязка показывает нарушение текущим приближением.
3. Для `x←Bx+c` нужна спектральная граница `ρ(B)<1`.
4. Сопряжённые градиенты используют вариационную форму SPD-системы.
5. Предобуславливание уменьшает влияние плохой обусловленности.

### Что написать на листе

1. **Понятия:** система `Ax=b`; приближение `x^k`; ошибка `e_k=x^k−x*`; невязка `r_k=b−Ax^k`.
2. **Стационарная итерация:** `x^(k+1)=Bx^k+c`; сходимость при любом старте ⇔ спектральный радиус `ρ(B)<1`.
3. **Методы:** Якоби использует только старые компоненты; Зейдель сразу использует обновлённые. Диагональное преобладание — достаточное условие.
4. **Вариационный подход:** для SPD-матрицы решение минимизирует `½xᵀAx−bᵀx`; метод сопряжённых градиентов эффективен для разреженных систем.
5. **Обусловленность:** большое `κ(A)` усиливает ошибки и замедляет итерации; предобуславливатель улучшает спектр эквивалентной системы.

### Говорить

Итерационный метод строит последовательность приближений к решению системы `Ax=b`. Невязка `r_k=b−Ax_k` показывает, насколько текущее приближение нарушает уравнение, а ошибка `e_k=x_k−x*` сравнивает его с точным решением.

В стационарном методе итерация имеет вид `x^(k+1)=Bx^k+c`. Ошибка удовлетворяет `e_(k+1)=Be_k`, поэтому сходимость при любом начальном приближении эквивалентна условию `ρ(B)<1`, где `ρ` — максимальный модуль собственного значения.

Метод Якоби вычисляет все новые компоненты только по старому вектору. Метод Гаусса–Зейделя сразу использует уже обновлённые компоненты и часто сходится быстрее. Достаточным условием их сходимости служит строгое диагональное преобладание; для Зейделя также важна симметричная положительная определённость.

Для симметричной положительно определённой матрицы решение системы одновременно минимизирует квадратичную функцию `½xᵀAx−bᵀx`. На этой вариационной трактовке основан метод сопряжённых градиентов — быстрый метод Крылова для больших разреженных систем.

Число обусловленности показывает, насколько ошибки данных усиливаются в решении. Большая обусловленность замедляет сходимость. Предобуславливатель заменяет систему эквивалентной, но с более удобным спектром.

## 2.5. Задача Коши для ОДУ

### Пять пунктов для запоминания

1. Задача Коши задаёт уравнение и начальное значение.
2. Эйлер идёт по текущей касательной.
3. Рунге–Кутта усредняет несколько наклонов внутри шага.
4. Жёсткость требует устойчивых неявных методов.
5. Сходимость многошагового метода требует согласованности и нуль-устойчивости.

### Что написать на листе

1. **Задача Коши:** `y'=f(t,y)`, `y(t₀)=y₀`; сетка `t_n=t₀+nh`, требуется найти `y_n≈y(t_n)`.
2. **Одношаговые методы:** Эйлер `y_(n+1)=y_n+hf(t_n,y_n)` — порядок 1; RK4 использует четыре наклона — порядок 4.
3. **Погрешность:** локальная относится к одному шагу, глобальная накапливается; порядок p означает глобальную ошибку `O(h^p)`.
4. **Жёсткость:** явный метод требует малого h ради устойчивости; неявный Эйлер требует решения уравнения, но допускает большие шаги.
5. **Многошаговые:** Адамс–Башфорт — явный, Адамс–Моултон и BDF — неявные; согласованность + нуль-устойчивость ⇒ сходимость.

### Говорить

Задача Коши для обыкновенного дифференциального уравнения состоит в нахождении функции из условия `y'=f(t,y)` и известного начального значения `y(t₀)=y₀`. Численный метод строит значения на сетке `t_n=t₀+nh`.

Метод Эйлера использует текущий наклон: `y_(n+1)=y_n+h f(t_n,y_n)`. Он имеет первый глобальный порядок. Методы Рунге–Кутты вычисляют несколько промежуточных наклонов внутри шага. Классический RK4 использует четыре наклона и имеет глобальный порядок четыре.

Локальная ошибка относится к одному шагу при точном входе, глобальная — к накопленному отклонению на всём интервале. Порядок метода показывает скорость уменьшения глобальной ошибки при уменьшении шага. Практические методы используют пару формул разных порядков для оценки ошибки и автоматического выбора h.

Жёсткая система содержит быстро затухающие и медленные процессы. Явный метод вынужден брать очень малый шаг ради устойчивости, даже когда точность этого не требует. Неявный Эйлер использует значение на новом слое и требует решения уравнения, зато устойчив при больших шагах.

Многошаговые методы используют несколько прошлых значений: Адамс–Башфорт является явным, Адамс–Моултон — неявным, BDF применяется к жёстким задачам. Для линейных многошаговых методов согласованность вместе с нуль-устойчивостью обеспечивает сходимость.

## 2.6. Разностные схемы: аппроксимация, устойчивость, сходимость

### Пять пунктов для запоминания

1. Сетка заменяет непрерывную область конечными узлами.
2. Производные заменяются конечными разностями.
3. Аппроксимация измеряет дефект дискретного уравнения.
4. Устойчивость не позволяет возмущениям разрастаться.
5. Аппроксимация вместе с устойчивостью приводит к сходимости.

### Что написать на листе

1. **Сетка:** `x_i=a+ih`; непрерывная функция заменяется значениями `u_i`, производные — конечными разностями.
2. **Пример:** для `−u''=f` используется `−(u_(i−1)−2u_i+u_(i+1))/h²=f_i` плюс дискретные граничные условия.
3. **Аппроксимация:** точное решение подставляется в схему; полученная невязка здесь имеет порядок `O(h²)`.
4. **Устойчивость:** ошибка решения ограничена ошибкой данных с константой, не растущей при `h→0`.
5. **Сходимость:** `u_h→u`; основная связь — аппроксимация вместе с устойчивостью обеспечивает сходимость.

### Говорить

Разностная схема заменяет непрерывную задачу системой уравнений на сетке. Для краевой задачи второго порядка `−u''=f` производную в узле заменяют центральной разностью. В результате неизвестными становятся значения `u_i`, а задача сводится к трёхдиагональной системе линейных уравнений.

Аппроксимация характеризует, насколько точно значения точного гладкого решения удовлетворяют дискретным уравнениям. Для центральной второй разности невязка имеет порядок `O(h²)`. Устойчивость означает, что небольшие возмущения правой части, границы или округления вызывают контролируемое изменение сеточного решения. Сходимость означает, что при `h→0` сеточное решение приближается к точному в выбранной норме.

Главная логическая связь такова: согласованная, то есть аппроксимирующая, схема при наличии устойчивости сходится. Аппроксимация говорит, что мы решаем почти правильное уравнение; устойчивость не позволяет малому дефекту превратиться в большую ошибку. Одно без другого недостаточно.

При ответе нужно также указать способ задания граничных условий и норму, в которой рассматриваются оценки. В вычислительной реализации важны структура матрицы и эффективный метод решения полученной системы.

## 2.7. Задача Дирихле для уравнения Пуассона

### Пять пунктов для запоминания

1. Пуассон связывает кривизну поля с источниками.
2. Дирихле задаёт само решение на границе.
3. В двумерном случае применяется пятиточечный шаблон.
4. Дискретный максимум даёт единственность и устойчивость.
5. После дискретизации решается большая разреженная система.

### Что написать на листе

1. **Задача:** `−Δu=f` в области Ω, `u=g` на границе; f — источники, g — заданное поле на границе.
2. **Схема:** на квадратной сетке `4u_ij−u_(i−1,j)−u_(i+1,j)−u_(i,j−1)−u_(i,j+1)=h²f_ij`.
3. **Принцип максимума:** при правильных знаках внутренний максимум контролируется границей и правой частью; отсюда единственность.
4. **Обоснование:** центральный шаблон имеет `O(h²)`; принцип максимума даёт устойчивость, следовательно, сходимость.
5. **Вычисления:** получается большая разреженная SPD-система; применяют сопряжённые градиенты, предобуславливание и многосеточные методы.

### Говорить

Уравнение Пуассона `−Δu=f` описывает, например, стационарное температурное или потенциальное поле с распределёнными источниками. В задаче Дирихле значения решения `u=g` задаются на границе области.

В прямоугольной двумерной области вводят сетку. Лапласиан заменяют пятиточечным шаблоном: центральное значение связано с четырьмя соседями. При `f=0` значение в узле является средним соседних, поэтому без источника внутри не может самопроизвольно возникнуть новый максимум.

Это выражается дискретным принципом максимума: при правильной знаковой структуре максимум и минимум контролируются границей и правой частью. Принцип используется для доказательства единственности и устойчивости схемы. Центральный шаблон аппроксимирует лапласиан со вторым порядком, а устойчивость приводит к сходимости того же порядка при достаточной гладкости решения.

Практическая специфика — очень большая, но разреженная система. Матрица обычно симметрична и положительно определена. Её решают методом сопряжённых градиентов, многосеточными методами или стационарными итерациями; явное хранение всех нулей не требуется.

## 2.8. Нестационарная теплопроводность

### Пять пунктов для запоминания

1. Температура меняется и в пространстве, и во времени.
2. Явная схема проста, но требует `r≤1/2`.
3. Неявная схема требует СЛАУ, но безусловно устойчива.
4. Кранк–Николсон имеет второй порядок по времени.
5. Устойчивость проверяют по коэффициентам усиления мод.

### Что написать на листе

1. **Уравнение:** `u_t=a²u_xx`; h — шаг пространства, τ — шаг времени, `r=a²τ/h²`.
2. **Явная схема:** `u_i^(n+1)=u_i^n+r(u_(i−1)^n−2u_i^n+u_(i+1)^n)`; в 1D устойчива при `r≤1/2`.
3. **Неявная схема:** новый слой находится из СЛАУ; безусловно устойчива, но дороже одного шага.
4. **Кранк–Николсон:** усредняет два слоя, имеет второй порядок по времени; возможны колебания на резких данных.
5. **Разделение переменных:** решение раскладывается на пространственные моды; устойчивость требует модуль коэффициента усиления ≤1.

### Говорить

Нестационарное уравнение теплопроводности `u_t=a²u_xx` описывает изменение температуры и в пространстве, и во времени. Сетка имеет пространственный шаг h и временной шаг τ.

Явная схема вычисляет новый слой только по известному старому: `u_i^(n+1)=u_i^n+r(u_(i−1)^n−2u_i^n+u_(i+1)^n)`, где `r=a²τ/h²`. Она проста, но в одномерном случае устойчива только при `r≤1/2`. Поэтому уменьшение h вдвое требует примерно четырёхкратного уменьшения τ.

Неявная схема использует соседние значения на новом слое и требует решения линейной системы, зато является безусловно устойчивой. Схема Кранка–Николсон усредняет явный и неявный операторы и имеет второй порядок по времени.

Для анализа разделяют переменные: сеточное решение раскладывают по собственным пространственным модам. Каждая мода на временном шаге умножается на коэффициент усиления. Если его модуль не превосходит единицы для всех мод, возмущения не растут. Так получают условия устойчивости. Совместно с аппроксимацией устойчивость обосновывает сходимость схемы.

## 2.9. Методы решения краевых задач

### Пять пунктов для запоминания

1. Краевые условия задаются на разных концах или границе.
2. Интегрально-интерполяционный метод сохраняет баланс.
3. Галёркин делает невязку ортогональной базису.
4. Ритц минимизирует энергетический функционал.
5. МКЭ использует локальные функции и разреженную сборку.

### Что написать на листе

1. **Краевая задача:** условия задаются на разных концах или границе; слабая форма получается умножением на тестовую функцию и интегрированием по частям.
2. **Интегрально-интерполяционный метод:** интегрировать закон по ячейке; баланс «вошло − вышло = источник».
3. **Бубнов–Галёркин:** `u_N=Σc_jφ_j`, невязка `R=Lu_N−f`; условия `(R,φ_i)=0`.
4. **Ритц:** если задача вариационная, подставить `u_N` в энергетический функционал и минимизировать по коэффициентам.
5. **МКЭ:** разбить область на элементы, использовать локальные базисы, собрать разреженную матрицу и учесть граничные условия.

### Говорить

В краевой задаче условия задаются на разных концах интервала или на границе области, в отличие от задачи Коши, где все начальные данные заданы в одной точке. Прямое интегрирование поэтому обычно невозможно без подбора неизвестных начальных данных.

Интегрально-интерполяционный метод интегрирует исходный закон по малой ячейке и заменяет потоки на её гранях разностными выражениями. Получается дискретный баланс: входящий поток минус выходящий равен источнику. Метод естественно сохраняет физические законы.

В методе Бубнова–Галёркина приближённое решение представляют как `u_N=Σc_jφ_j`. После подстановки возникает невязка R. Коэффициенты выбирают так, чтобы невязка была ортогональна каждой базисной функции: `(R,φ_i)=0`.

Метод Ритца применим, когда задача эквивалентна минимуму энергетического функционала. Приближение подставляют в энергию и минимизируют по коэффициентам. Метод конечных элементов использует слабую постановку и локальные базисные функции на разбиении области. Из-за локальности получается разреженная матрица. Таким образом, Галёркин, Ритц и МКЭ связаны через слабую форму, но исходят из разных интерпретаций.

## 2.10. Нелинейные уравнения и системы

### Пять пунктов для запоминания

1. Бисекция медленная, но имеет надёжную гарантию.
2. Ньютон использует касательную и локально сходится квадратично.
3. Секущая заменяет производную двумя значениями.
4. Простая итерация сходится при сжатии.
5. Для системы Ньютон решает уравнение с матрицей Якоби.

### Что написать на листе

1. **Отделение корня:** найти `[a,b]`, где f непрерывна и `f(a)f(b)<0`; тогда внутри существует корень.
2. **Бисекция:** делить отрезок пополам, сохранять смену знака; после k шагов длина `(b−a)/2^k`, сходимость линейная.
3. **Ньютон:** `x_(k+1)=x_k−f(x_k)/f'(x_k)`; возле простого корня сходимость квадратичная, но нужен хороший старт.
4. **Другие методы:** секущая не требует производной; простая итерация `x_(k+1)=φ(x_k)` сходится при `|φ'|≤q<1`.
5. **Система:** решить `J(x_k)Δx=−F(x_k)`, затем `x_(k+1)=x_k+Δx`; применять демпфирование и проверять поправку и невязку.

### Говорить

Задача состоит в нахождении корня уравнения `f(x)=0` или системы `F(x)=0`. Сначала корень желательно отделить, то есть найти интервал, где функция непрерывна и меняет знак.

Метод бисекции делит этот интервал пополам и сохраняет половину со сменой знака. Он сходится линейно, но надёжен: после k шагов длина интервала уменьшается в `2^k` раз.

Метод Ньютона заменяет функцию касательной: `x_(k+1)=x_k−f(x_k)/f'(x_k)`. Вблизи простого корня при достаточной гладкости он сходится квадратично, то есть число верных цифр примерно удваивается. Однако плохое начальное приближение или малая производная могут привести к расходимости. Метод секущих заменяет производную наклоном по двум последним точкам.

Метод простой итерации записывает уравнение как `x=φ(x)`. Если φ является сжатием, например `|φ'|≤q<1`, теорема Банаха гарантирует единственный корень и сходимость.

Для системы метод Ньютона на каждом шаге решает линейную систему `J(x_k)Δx=−F(x_k)` с матрицей Якоби и полагает `x_(k+1)=x_k+Δx`. Матрицу не обращают явно. Для надёжности применяют уменьшение шага. Останавливаются по малости и поправки, и невязки.

# Раздел 3. Структуры и алгоритмы обработки данных и знаний

## 3.1. Понятие алгоритма, запись, конструкции и эффективность

### Пять пунктов для запоминания

1. Алгоритм — конечная однозначная инструкция.
2. Его записывают словами, схемой, псевдокодом или программой.
3. Основные конструкции — следование, ветвление и цикл.
4. Корректность включает правильность и завершение.
5. Эффективность оценивает время и память по размеру входа.

### Что написать на листе

1. **Определение:** алгоритм — конечная однозначная последовательность действий, преобразующая допустимый вход в требуемый результат.
2. **Свойства:** дискретность, определённость, конечность, массовость и результативность.
3. **Запись:** словесное описание, блок-схема, псевдокод и программа; уровень точности последовательно возрастает.
4. **Конструкции:** следование, ветвление и цикл; рекурсия требует базового случая и уменьшения задачи.
5. **Оценка:** корректность = правильность + завершение; время и память задаются через `O`, `Ω`, `Θ` по размеру входа n.

### Говорить

Алгоритм — конечная однозначная последовательность действий, которая для допустимых входных данных выдаёт требуемый результат. Его свойства: дискретность шагов, определённость каждой команды, завершение за конечное число шагов, применимость к классу входов и получение результата.

Алгоритм можно записать обычным языком, блок-схемой, псевдокодом или программой. Словесная форма удобна человеку, псевдокод не зависит от языка, а программа является точной исполнимой реализацией.

Основные управляющие конструкции — следование, когда команды выполняются по порядку; ветвление, выбирающее путь по условию; и цикл, повторяющий действия. Рекурсия вызывает алгоритм на меньшей задаче и требует базового случая.

Корректность означает, что для каждого допустимого входа алгоритм завершается и возвращает правильный результат. Частичную корректность доказывают, например, инвариантом цикла, а завершение — строгим уменьшением некоторой меры.

Эффективность оценивают по размеру входа n. `O` задаёт верхнюю асимптотическую границу, `Ω` — нижнюю, `Θ` — границу с обеих сторон. Отдельно оценивают время и дополнительную память, а также лучший, средний и худший случаи. Асимптотика описывает рост, а не точное число секунд.

## 3.2. Структуры данных, АТД и массивы

### Пять пунктов для запоминания

1. Структура данных описывает физическое хранение.
2. АТД описывает операции независимо от реализации.
3. Массив хранит элементы подряд и даёт доступ `O(1)`.
4. Вставка в середину требует сдвига `O(n)`.
5. Добавление в динамический массив амортизированно стоит `O(1)`.

### Что написать на листе

1. **Структура данных:** физическая организация значений в памяти. **АТД:** интерфейс и смысл операций независимо от реализации.
2. **Массив:** однотипные элементы лежат подряд; адрес `a[i]=base+i·size`, поэтому индексный доступ `O(1)`.
3. **Операции:** линейный поиск `O(n)`; вставка и удаление в середине со сдвигом `O(n)`.
4. **Динамический массив:** различаются размер и ёмкость; при заполнении выделяется больший блок и выполняется копирование `O(n)`.
5. **Амортизация:** расширение редкое, поэтому серия добавлений в конец даёт среднюю стоимость `O(1)` на операцию.

### Говорить

Структура данных определяет организацию значений в памяти и способы доступа к ним. Абстрактный тип данных задаёт логический набор операций и их смысл, не фиксируя реализацию. Например, стек как АТД может быть реализован массивом или связным списком.

Массив хранит однотипные элементы в последовательных ячейках памяти. Адрес элемента вычисляется по индексу, поэтому доступ `a[i]` занимает `O(1)`. Последовательное размещение обеспечивает хорошую локальность кэша.

Поиск в неотсортированном массиве требует `O(n)`. Вставка или удаление в середине обычно требует сдвига до n элементов и также стоит `O(n)`. Статический массив имеет фиксированный размер. Динамический массив хранит логический размер и ёмкость выделенного блока. При заполнении создаётся больший блок и элементы переносятся.

Одно расширение стоит `O(n)`, но происходит редко, поэтому добавление в конец имеет амортизированную стоимость `O(1)`. При выборе структуры нужно учитывать не только отдельную операцию, но и набор операций, частоту изменений, расход памяти и требования к порядку.

## 3.3. Однопроходные алгоритмы по массиву

### Пять пунктов для запоминания

1. Каждый элемент просматривается не более одного раза.
2. Накопитель хранит результат обработанного префикса.
3. Инвариант доказывает правильность каждого шага.
4. Инициализация должна учитывать пустой и отрицательный вход.
5. Обычно время `Θ(n)`, а память `O(1)`.

### Что написать на листе

1. **Однопроходность:** каждый элемент читается один раз; хранится только краткое состояние обработанного префикса.
2. **Шаблоны:** сумма, min/max и индекс, количество по условию, проверка монотонности, два лучших значения.
3. **Инвариант:** после обработки первых i элементов аккумулятор содержит правильный ответ для префикса `a[0:i]`.
4. **Границы:** отдельно обработать пустой массив; экстремум инициализировать первым элементом, а не нулём; оговорить равные значения.
5. **Сложность:** время `Θ(n)`, дополнительная память `O(1)`; для многих задач каждый элемент необходимо увидеть.

### Говорить

Однопроходный алгоритм читает каждый элемент массива не более одного раза и поддерживает небольшое состояние — накопитель. Например, для суммы хранится текущая сумма, для максимума — лучшее значение и его индекс, для подсчёта — счётчик.

Корректность удобно доказывать инвариантом. Для поиска максимума инвариант утверждает: перед обработкой позиции i сохранённое значение является максимумом префикса `a[0:i]`. Сначала утверждение верно для первого элемента. На шаге максимум либо остаётся прежним, либо заменяется новым элементом. После последнего шага префикс совпадает со всем массивом.

Максимум нельзя безусловно инициализировать нулём, поскольку все элементы могут быть отрицательными. Нужно взять первый элемент или отдельно обработать отсутствие данных. Также оговаривают, что делать при равных максимумах, и учитывают переполнение суммы.

Одним проходом решаются сумма, минимум и максимум, количество элементов по условию, проверка монотонности, удаление соседних повторов и многие потоковые статистики. Время равно `Θ(n)`, дополнительная память часто `O(1)`. Для задач, где необходимо учитывать каждый элемент, эта оценка оптимальна.

## 3.4. Поиск элемента в массиве

### Пять пунктов для запоминания

1. Линейный поиск работает без сортировки за `O(n)`.
2. Бинарный поиск требует упорядоченности.
3. На каждом шаге отбрасывается половина диапазона.
4. Инвариант границ защищает от ошибок реализации.
5. `lower_bound` находит первое значение не меньше искомого.

### Что написать на листе

1. **Линейный поиск:** проверять элементы слева направо; сортировка не требуется; худшее время `O(n)`, память `O(1)`.
2. **Бинарный поиск:** массив должен быть отсортирован; на каждом шаге отбрасывается половина, время `O(log n)`.
3. **Границы:** удобно использовать `[l,r)` и `mid=l+(r−l)//2`; обновлять `l=mid+1` или `r=mid`, чтобы диапазон уменьшался.
4. **Инвариант:** искомая позиция, если существует, остаётся в текущем диапазоне; `lower_bound` возвращает первую позицию с `a[i]≥x`.
5. **Практика:** проверить отсутствие и дубликаты; сортировка `O(n log n)` ради одного поиска невыгодна, но окупается для многих запросов.

### Говорить

Линейный поиск последовательно сравнивает искомое значение со всеми элементами и возвращает индекс первого совпадения или признак отсутствия. Он не требует упорядоченности и имеет худшую сложность `O(n)`.

Бинарный поиск применим к отсортированному массиву. Поддерживается диапазон, в котором ответ ещё возможен, например полуинтервал `[left,right)`. Вычисляется середина. Если средний элемент меньше искомого, левая граница переносится за середину; иначе правая граница становится равной середине. Диапазон каждый раз уменьшается примерно вдвое, поэтому время `O(log n)`.

Удобный вариант `lower_bound` находит первую позицию с элементом не меньше x. После завершения нужно проверить, находится ли позиция внутри массива и равно ли значение x. Такой вариант естественно обрабатывает дубликаты и даёт индекс вставки при отсутствии.

Основные ошибки — смешивание закрытых и полуоткрытых границ, отсутствие строгого уменьшения диапазона и выход за массив. Сортировать массив ради единственного поиска обычно невыгодно, но при большом числе запросов затраты `O(n log n)` на сортировку могут окупиться.

## 3.5. Списки, стек, очередь и дек

### Пять пунктов для запоминания

1. Список соединяет отдельные узлы ссылками.
2. Двусвязный список позволяет движение в обе стороны.
3. Стек работает по правилу LIFO.
4. Очередь работает по правилу FIFO.
5. Дек выполняет операции на обоих концах.

### Что написать на листе

1. **Список:** узел `(value,next)`; двусвязный добавляет `prev`. Доступ по номеру `O(n)`, вставка рядом с известным узлом `O(1)`.
2. **Стек:** LIFO; `push`, `pop`, `top`; применяется для вызовов, скобок и DFS.
3. **Очередь:** FIFO; добавление в хвост, удаление из головы; применяется в BFS и планировании.
4. **Дек:** добавление и удаление с двух концов; позволяет реализовать стек, очередь и скользящий максимум.
5. **Реализация:** массив, кольцевой буфер или список; сложность зависит от выбранной реализации и доступных концов.

### Говорить

Связный список состоит из отдельных узлов. Односвязный узел хранит значение и ссылку на следующий, двусвязный — также ссылку на предыдущий. Доступ по номеру требует прохода `O(n)`, зато вставка или удаление рядом с известным узлом выполняется за `O(1)`. Двусвязный список позволяет двигаться назад, но расходует больше памяти.

Стек работает по принципу LIFO: последний добавленный элемент извлекается первым. Основные операции — `push`, `pop` и просмотр вершины. Стек используется для вызовов функций, проверки скобок и обхода в глубину.

Очередь работает по принципу FIFO: первый добавленный элемент извлекается первым. Добавление выполняется в хвост, удаление — из головы. Она применяется в планировании и обходе графа в ширину. В массиве очередь реализуют кольцевым буфером, чтобы не сдвигать элементы.

Дек разрешает добавление и удаление с обоих концов. Все эти структуры являются абстрактными типами: один интерфейс может иметь разные реализации. Нужно сравнивать не названия, а стоимости требуемых операций.

## 3.6. Динамическое программирование и жадные алгоритмы

### Пять пунктов для запоминания

1. ДП хранит ответы повторяющихся подзадач.
2. Для ДП нужны состояние, переход и база.
3. Жадный алгоритм фиксирует лучший текущий выбор.
4. Жадность доказывают обменным аргументом.
5. Без доказательства жадный метод может дать неверный оптимум.

### Что написать на листе

1. **ДП:** требуется оптимальная подструктура и повторяющиеся подзадачи; определить состояние, переход и базу.
2. **Вычисление:** мемоизация — сверху вниз по запросу; табуляция — снизу вверх; отдельно сохранить выбор для восстановления ответа.
3. **Жадный метод:** на каждом шаге фиксировать локально лучший допустимый вариант без возврата.
4. **Доказательство:** обменный аргумент показывает, что первый жадный выбор можно включить в некоторое оптимальное решение.
5. **Примеры:** интервалы по раннему окончанию — оптимально; для монет `{1,3,4}` и суммы 6 жадность даёт 3 монеты вместо 2.

### Говорить

Динамическое программирование применяют при оптимальной подструктуре и перекрывающихся подзадачах. Нужно определить состояние, рекуррентный переход, базовые значения, порядок вычисления и способ восстановления решения. Мемоизация вычисляет состояния по запросу сверху вниз, табуляция заполняет таблицу снизу вверх.

Жадный алгоритм на каждом шаге делает локально лучший выбор и больше его не пересматривает. Он обычно проще и экономнее ДП, но корректность требует специального доказательства. Часто используется обменный аргумент: берут оптимальное решение, не содержащее жадного выбора, и заменяют его часть, не ухудшая результат.

Например, для максимального числа непересекающихся интервалов нужно выбирать интервал с самым ранним окончанием. Его можно поставить первым в некотором оптимальном решении, не мешая оставшимся. Но жадность не универсальна. Для монет `{1,3,4}` и суммы 6 выбор крупнейшей монеты даёт `4+1+1`, тогда как оптимально `3+3`.

В дробном рюкзаке жадность по ценности на единицу веса оптимальна, а в рюкзаке 0–1 — нет. Поэтому главное различие: ДП систематически сравнивает варианты, а жадный метод нуждается в доказанном свойстве жадного выбора.

## 3.7. Алгоритмы сортировки

### Пять пунктов для запоминания

1. Простые сортировки обычно требуют `O(n²)`.
2. Слияние гарантирует стабильные `O(n log n)`.
3. Quicksort быстр в среднем, но имеет худшее `O(n²)`.
4. Heapsort гарантирует `O(n log n)` при малой памяти.
5. Сравнительная сортировка не лучше `Ω(n log n)` в общем случае.

### Что написать на листе

1. **Простые методы:** пузырёк, выбор и вставки обычно `O(n²)`; вставки хороши на малых почти отсортированных массивах.
2. **Слияние:** деление и merge; гарантированно `O(n log n)`, стабильно, дополнительная память `O(n)`.
3. **Quicksort:** разбиение относительно pivot; в среднем `O(n log n)`, худшее `O(n²)`, обычно работает на месте.
4. **Heapsort:** куча; гарантированно `O(n log n)`, память `O(1)`, но сортировка нестабильна.
5. **Теория:** стабильность сохраняет порядок равных ключей; для сортировок сравнениями нижняя граница `Ω(n log n)`.

### Говорить

Сортировка переставляет элементы так, чтобы их ключи шли в заданном порядке. Важные свойства — время, дополнительная память, устойчивость и адаптивность. Устойчивая сортировка сохраняет взаимный порядок элементов с равными ключами.

Пузырьковая сортировка меняет соседние элементы, выбор каждый раз находит минимум, вставки помещают очередной элемент в уже отсортированный префикс. Их худшее время `O(n²)`, но вставки эффективны на небольших почти отсортированных данных.

Сортировка слиянием делит массив пополам, сортирует части и сливает их. Она гарантирует `O(n log n)` и стабильна, но требует `O(n)` памяти. Быстрая сортировка разбивает массив относительно опорного элемента; в среднем работает за `O(n log n)`, в худшем за `O(n²)`, обычно не требует большого дополнительного массива. Пирамидальная сортировка гарантирует `O(n log n)` и `O(1)` дополнительной памяти, но нестабильна.

Любая сортировка, использующая только сравнения, в худшем случае требует `Ω(n log n)` сравнений, поскольку должна различить `n!` перестановок. Сортировки подсчётом и поразрядная обходят эту границу, используя дополнительную информацию о ключах.

## 3.8. Сравнение сортировок, хеширование и деревья

### Пять пунктов для запоминания

1. Сортировку выбирают по времени, памяти и стабильности.
2. Хеш переводит ключ в номер корзины.
3. Коллизии решают цепочками или открытой адресацией.
4. Скорость дерева зависит от его высоты и баланса.
5. Дерево обходят preorder, inorder, postorder или по уровням.

### Что написать на листе

1. **Выбор сортировки:** сравнить худшее/среднее время, память, стабильность и предварительную упорядоченность данных.
2. **Хеширование:** `h:K→{0,…,m−1}`; коллизии неизбежны, разрешаются цепочками или открытой адресацией.
3. **Хеш-таблица:** коэффициент `α=n/m`; среднее время поиска/вставки `O(1)`, худшее `O(n)`; при заполнении выполняется рехеширование.
4. **Деревья:** BST имеет операции `O(h)`; баланс даёт `h=O(log n)`. Виды: AVL, красно-чёрное, B-дерево, куча, trie.
5. **Обходы:** preorder — корень первым; inorder BST даёт сортировку; postorder — корень последним; по уровням используется очередь. Все `O(n)`.

### Говорить

Алгоритм сортировки выбирают по худшему и среднему времени, памяти, устойчивости и свойствам данных. Слияние подходит для стабильности и внешних данных, quicksort часто быстр в оперативной памяти, heapsort даёт гарантию при малой памяти, вставки полезны для коротких почти упорядоченных участков.

Хеш-функция преобразует ключ в номер ячейки таблицы. Разные ключи могут получить один номер — это коллизия. При цепочках в ячейке хранится коллекция элементов; при открытой адресации ищется другая ячейка по последовательности проб. Коэффициент заполнения `α=n/m` влияет на скорость, поэтому таблицу периодически расширяют и рехешируют. При хорошем распределении поиск, вставка и удаление выполняются в среднем за `O(1)`, но в худшем за `O(n)`.

Дерево — связный граф без циклов; в корневом дереве определены родитель, дети, глубина и высота. В двоичном дереве поиска меньшие ключи лежат слева, большие справа. Операции стоят `O(h)`: `O(log n)` при балансе и `O(n)` у вырожденного дерева. AVL и красно-чёрные деревья поддерживают баланс, B-деревья используются на диске, куча реализует приоритетную очередь, trie хранит строки по префиксам.

Обходы в глубину бывают прямой, симметричный и обратный. Симметричный обход BST даёт отсортированные ключи. Обход по уровням выполняется очередью. Каждый полный обход занимает `O(n)`.

## 3.9. Реализация однопроходных алгоритмов

### Пять пунктов для запоминания

1. Сначала формулируется контракт функции.
2. Экстремум инициализируется первым элементом, а не нулём.
3. Один цикл обновляет краткое состояние.
4. Инвариант относится к уже обработанному префиксу.
5. Нужны крайние тесты и оценки `Θ(n)`, `O(1)`.

### Что написать на листе

1. **Контракт:** вход — непустой массив; выход — индекс и значение первого максимума; для пустого массива — ошибка или специальный результат.
2. **Инициализация:** `best_i=0`; нельзя начинать с нуля как значения, потому что все элементы могут быть отрицательными.
3. **Цикл:** для `i=1…n−1`, если `a[i]>a[best_i]`, присвоить `best_i=i`; строгое сравнение сохраняет первый максимум.
4. **Инвариант:** `best_i` указывает на максимум уже обработанного префикса; доказать инициализацию, сохранение и завершение.
5. **Проверка:** пустой, один элемент, отрицательные и повторы; время `Θ(n)`, память `O(1)`.

### Говорить

В практическом вопросе сначала формулирую контракт: функция получает массив и возвращает индекс и значение максимума, а для пустого массива сообщает об ошибке. Максимум инициализирую первым элементом, поскольку ноль ошибочен для полностью отрицательного массива. Затем одним циклом сравниваю каждый следующий элемент с текущим лучшим и при необходимости обновляю индекс.

Инвариант цикла: перед обработкой позиции i сохранённый индекс указывает на максимум префикса `a[0:i]`. Он верен после инициализации. Сравнение с новым элементом сохраняет его. После завершения префикс равен всему массиву, значит результат корректен.

Проверяю пустой и одноэлементный массивы, отрицательные числа, повторяющиеся максимумы и уже упорядоченные данные. Если нужен первый максимум, обновляю только при строгом `>`; если последний — при `≥`. Цикл делает n сравнений с точностью до константы, поэтому время `Θ(n)`, дополнительная память `O(1)`. По такой же схеме реализуются сумма, подсчёт, минимум и проверка монотонности.

## 3.10. Реализация поиска

### Пять пунктов для запоминания

1. Нужно заранее определить результат при отсутствии.
2. Бинарный поиск использует одну схему границ последовательно.
3. Середина вычисляется без потенциального переполнения.
4. Диапазон обязан строго уменьшаться.
5. Проверяются пустота, края, отсутствие и дубликаты.

### Что написать на листе

1. **Линейный код:** пройти индексы, при `a[i]==x` вернуть i; после цикла вернуть `−1`; время `O(n)`.
2. **Бинарные границы:** `l=0`, `r=n`, полуинтервал `[l,r)`; условие цикла `l<r`.
3. **Шаг:** `mid=l+(r−l)//2`; если `a[mid]<x`, то `l=mid+1`, иначе `r=mid`.
4. **Результат:** после цикла l — первая позиция `a[l]≥x`; совпадение есть при `l<n` и `a[l]==x`.
5. **Доказательство и тесты:** диапазон строго уменьшается, инвариант сохраняется; проверить пустоту, края, отсутствие и дубликаты; время `O(log n)`.

### Говорить

Линейный поиск проходит массив слева направо и возвращает индекс при первом равенстве; если цикл завершился, возвращает минус один. Он работает на любом массиве за `O(n)`.

Для бинарного поиска заранее требуется сортировка. Я использую полуинтервал `[left,right)`, первоначально `[0,n)`. Пока `left<right`, вычисляю `mid=left+(right−left)//2`. Если `a[mid]<x`, первая подходящая позиция находится правее, поэтому `left=mid+1`. Иначе сохраняю середину как возможный ответ и делаю `right=mid`.

Инвариант: все элементы до left меньше x, все элементы начиная с right не меньше x, а ответ находится между границами. Диапазон строго сокращается, поэтому цикл завершается. После него left является индексом первого элемента не меньше x. Для обычного поиска проверяю `left<n` и `a[left]==x`, иначе элемента нет.

Тесты: пустой массив, один элемент, значение меньше всех и больше всех, отсутствие между соседями, несколько повторов и элементы на границах. Время бинарного поиска `O(log n)`, память итеративной версии `O(1)`.

## 3.11. Реализация сортировки

### Пять пунктов для запоминания

1. Код должен упорядочить и сохранить все элементы.
2. Инвариант вставок — отсортированный префикс.
3. Строгое сравнение сохраняет стабильность равных ключей.
4. Нужно назвать лучший, средний и худший случаи.
5. Тестируются пустота, повторы и обратный порядок.

### Что написать на листе

1. **Алгоритм вставок:** для каждого i сохранить `key=a[i]`, сдвинуть вправо предыдущие элементы больше key, вставить key.
2. **Инвариант:** перед шагом i префикс `a[0:i]` отсортирован и содержит исходные элементы этого префикса.
3. **Стабильность:** внутреннее условие `a[j]>key`, а не `≥`; равные ключи не меняются местами.
4. **Сложность:** лучший случай `Θ(n)`, средний и худший `Θ(n²)`, дополнительная память `O(1)`.
5. **Тесты:** пустой, один элемент, обратный порядок, дубликаты и отрицательные; проверить порядок и сохранение мультимножества.

### Говорить

В качестве простой реализации беру сортировку вставками. Внешний цикл идёт от второго элемента. Текущий элемент сохраняется в переменной key. Пока предыдущие элементы больше key, я сдвигаю их вправо. Затем помещаю key в освободившуюся позицию.

Инвариант: перед итерацией с индексом i префикс `a[0:i]` уже отсортирован и содержит те же элементы, что исходный префикс. Внутренний цикл только сдвигает большие элементы и вставляет key в правильное место, поэтому инвариант сохраняется. После последней итерации отсортирован весь массив.

Сравнение должно быть строгим `a[j]>key`: тогда равные элементы не меняют взаимный порядок, и сортировка стабильна. На уже отсортированном массиве внутренний цикл почти не работает, время `Θ(n)`. В среднем и худшем случае, например на обратном порядке, время `Θ(n²)`. Дополнительная память `O(1)`.

Корректный результат должен удовлетворять двум свойствам: значения идут неубывающе, и мультимножество элементов не изменилось. Тестирую пустой массив, один элемент, обратный порядок, повторы, отрицательные числа и все равные элементы. Для больших данных вместо вставок применяют слияние или гибридную сортировку `O(n log n)`.

## 3.12. Реализация жадного алгоритма

### Пять пунктов для запоминания

1. Жадный критерий выбирается до написания кода.
2. Сортировка или очередь задаёт порядок кандидатов.
3. Инвариант подтверждает допустимость выбранного набора.
4. Обменный аргумент доказывает глобальную оптимальность.
5. Контрпример показывает границы применимости жадности.

### Что написать на листе

1. **Задача:** выбрать максимальное число непересекающихся интервалов; кандидат задаётся `(start,end)`.
2. **Критерий:** отсортировать по end и брать интервал, если `start≥last_end`; после выбора обновить `last_end=end`.
3. **Инвариант:** выбранные интервалы совместимы, а последний конец минимален среди решений такого размера.
4. **Доказательство обменом:** первый интервал оптимального решения заменить самым рано заканчивающимся; остальные не пострадают.
5. **Оценка и граница:** сортировка `O(n log n)`, проход `O(n)`; жадность не универсальна — монеты `{1,3,4}`, сумма 6.

### Говорить

Рассмотрю задачу выбора максимального числа непересекающихся интервалов. Жадный критерий — каждый раз брать допустимый интервал с самым ранним временем окончания. Сначала сортирую интервалы по правому концу. Затем одним проходом добавляю интервал, если его начало не меньше конца последнего выбранного.

После каждого шага выбранные интервалы не пересекаются — это инвариант допустимости. Докажу оптимальность обменным аргументом. Пусть некоторое оптимальное решение начинается не с интервала, заканчивающегося раньше всех. Заменим его первый интервал нашим. Новый заканчивается не позже, поэтому не мешает ни одному из последующих интервалов. Размер решения не уменьшился. Значит существует оптимальное решение с жадным первым выбором, а затем аргумент повторяется для оставшейся части.

Сортировка занимает `O(n log n)`, проход — `O(n)`, общая сложность `O(n log n)`. Если интервалы уже отсортированы по концам, остаётся линейное время.

Важно отметить, что жадный алгоритм не универсален. Для монет `{1,3,4}` и суммы 6 выбор крупнейшей монеты даёт три монеты `4+1+1`, хотя оптимум — две монеты `3+3`. Поэтому без обменного доказательства жадный код является только эвристикой.
