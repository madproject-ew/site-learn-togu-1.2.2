# Раздел 1. Дискретная математика и математическое моделирование

## 1.1. Алгебра множеств. Конечные и бесконечные множества. Теорема Кантора–Бернштейна. Системы уравнений в алгебре множеств

- **Операции:** ∪, ∩, \, Δ (симметрическая разность), дополнение. Алгебра множеств = булева алгебра: коммутативность, ассоциативность, дистрибутивность в обе стороны, законы де Моргана, идемпотентность, поглощение.
- **Изоморфизм** булевой алгебре логики через характеристическую функцию χ_A(x): ∩↔∧, ∪↔∨, дополнение↔отрицание, Δ↔⊕.
- **Равномощность:** |A| = |B| ⟺ ∃ биекция. Конечное — равномощно отрезку {1..n}. Счётное — равномощно ℕ. Континуум — равномощно [0,1].
- **Теорема Кантора–Бернштейна:** если существуют инъекции f: A→B и g: B→A, то существует биекция A↔B. Идея доказательства: разбиение A и B на «цепочки» по итерациям g∘f и склейка биекции по цепочкам.
- **Теорема Кантора:** |A| < |2^A| для любого A (диагональный метод) ⟹ нет наибольшей мощности, иерархия бесконечностей.
- Счётность ℚ, несчётность ℝ (диагональ), континуум-гипотеза (Гёдель–Коэн: независима от ZFC).
- **Системы уравнений в алгебре множеств:** переход к характеристическим функциям ⟹ система булевых уравнений; решается сведением к одному уравнению F = 0 (или F = 1) и перебором/методом Жегалкина. Критерий разрешимости и описание общего решения через свободные параметры-множества.

## 1.2. Алгебра логики. Алгебра Жегалкина. Совершенные нормальные формы. Теорема Поста

- Булева функция f: {0,1}ⁿ→{0,1}; всего 2^(2ⁿ) функций от n переменных.
- **СДНФ:** дизъюнкция конституент единицы (по строкам, где f=1). **СКНФ:** конъюнкция конституент нуля. Существуют и единственны для любой f ≠ const.
- **Алгебра Жегалкина:** базис {⊕, ∧, 1}, кольцо характеристики 2. **Полином Жегалкина** существует и единственен для любой f: f = a₀ ⊕ ⊕aᵢxᵢ ⊕ ⊕aᵢⱼxᵢxⱼ ⊕ … Способы построения: метод неопределённых коэффициентов, треугольник Паскаля, преобразование СДНФ (x̄ = x⊕1, a∨b = a⊕b⊕ab).
- **Пять предполных (замкнутых) классов Поста:**
  - T₀ — сохраняющие 0: f(0,…,0)=0;
  - T₁ — сохраняющие 1: f(1,…,1)=1;
  - S — самодвойственные: f(x̄) = ¬f(x);
  - M — монотонные;
  - L — линейные (полином Жегалкина степени ≤ 1).
- **Теорема Поста о функциональной полноте:** система F полна ⟺ F не содержится целиком ни в одном из пяти классов T₀, T₁, S, M, L. Практика: строим таблицу Поста (5 столбцов), в каждом столбце должен быть «минус».
- Следствия: {¬, ∧}, {¬, ∨}, {|} (штрих Шеффера), {↓} — полные системы. Базис — полная система, никакая собственная подсистема которой не полна; максимальная мощность базиса — 4.

## 1.3. Линейные оптимизационные модели. Симплекс-метод

- **Общая ЗЛП:** c᾿x → max, Ax ≤ b, x ≥ 0. **Каноническая форма:** равенства + неотрицательность (вводим слабые переменные).
- **Геометрия:** допустимое множество — выпуклый многогранник; оптимум достигается в вершине (если конечен). **Вершина ⟺ базисное допустимое решение** — ключевая теорема, обосновывающая перебор только базисов.
- **Итерация симплекс-метода:** симплекс-таблица → оценки Δⱼ = cⱼ − z ⱼ → критерий оптимальности (для max: все Δⱼ ≤ 0) → выбор ведущего столбца (max Δⱼ) → ведущей строки по минимальному симплекс-отношению → пересчёт по методу Жордана–Гаусса.
- **Патологии:** вырожденность и зацикливание (лечится правилом Бланда или лексикографическим правилом); неограниченность (в ведущем столбце нет положительных элементов); поиск начального базиса — метод искусственного базиса / M-метод / двухфазный.
- **Двойственность:** двойственная задача, теоремы двойственности (слабая, сильная), условия дополняющей нежёсткости; экономическая интерпретация двойственных оценок как теневых цен ресурсов.
- **Сложность:** симплекс-метод экспоненциален в худшем случае (пример Кли–Минти), но эффективен на практике; полиномиальные альтернативы — метод эллипсоидов Хачияна, метод внутренней точки Кармаркара.

## 1.4. Экстремальные задачи переборного типа: рюкзак, коммивояжёр, назначения

- Общая черта: конечное, но экспоненциально большое множество допустимых решений; задачи целочисленного/комбинаторного программирования.
- **Задача о ранце (0-1):** max Σvᵢxᵢ при Σwᵢxᵢ ≤ W, xᵢ∈{0,1}. NP-трудная. ДП: F(i, w) = max{F(i−1,w), F(i−1,w−wᵢ)+vᵢ}, трудоёмкость O(nW) — **псевдополиномиальная** (W входит по величине, не по длине записи). Дробный рюкзак решается жадно по vᵢ/wᵢ — точно и за O(n log n). FPTAS для 0-1.
- **Коммивояжёр (TSP):** гамильтонов цикл минимального веса. NP-трудная; в общем виде не аппроксимируема с любой константой (если P≠NP). Полный перебор O(n!), ДП Хелда–Карпа O(n²·2ⁿ). Метод ветвей и границ (нижняя граница — минимальное остовное дерево, венгерский метод); метрический TSP — 2-приближение через MST, алгоритм Кристофидеса — 3/2. Эвристики: ближайший сосед, 2-opt, Лин–Кернигана, муравьиные алгоритмы.
- **Задача о назначениях:** min Σcᵢⱼxᵢⱼ, каждый исполнитель — одной работе. Частный случай транспортной задачи; матрица ограничений вполне унимодулярна ⟹ ЛП-релаксация даёт целочисленное решение. **Полиномиально разрешима**: венгерский алгоритм O(n³). Важный акцент на экзамене: три задачи из одного «переборного» списка, но третья — не NP-трудная.
- **Общие схемы точного решения:** метод ветвей и границ, метод отсечений Гомори, динамическое программирование.

## 1.5. Графы. Эйлеровы и гамильтоновы графы. Деревья. Планарность. Раскраска. Оптимизационные задачи

- **Эйлеров цикл** (проходит каждое ребро ровно раз): **теорема Эйлера** — существует ⟺ граф связен и все степени чётны; эйлеров путь ⟺ ровно 0 или 2 вершины нечётной степени. Алгоритм Флёри / Хирхольцера, O(E). Задача китайского почтальона.
- **Гамильтонов цикл** (через каждую вершину ровно раз): критерия нет, задача NP-полная. Достаточные условия: **Дирака** (deg v ≥ n/2 для всех v, n ≥ 3), **Оре** (deg u + deg v ≥ n для несмежных u,v), теорема Хватала. Обязательно проговорить контраст: для эйлеровости — критерий, для гамильтоновости — только достаточные условия.
- **Деревья:** связный ациклический граф. Эквивалентные определения: n−1 ребро + связность; единственный путь между любыми вершинами. Число помеченных деревьев — **формула Кэли** n^(n−2). **Кодирование:** код Прюфера (биекция деревьев на n вершинах и слов длины n−2), обходы, скобочная запись.
- **Планарность:** укладка на плоскости. **Формула Эйлера** V − E + F = 2; следствия E ≤ 3V − 6, E ≤ 2V − 4 для двудольных. **Критерий Понтрягина–Куратовского:** граф планарен ⟺ не содержит подграфов, гомеоморфных K₅ или K₃,₃. Критерий Вагнера (миноры). Алгоритм Хопкрофта–Тарьяна за O(V).
- **Раскраска плоского графа:** хроматическое число; теорема о пяти красках (простое доказательство индукцией); **теорема о четырёх красках** (Аппель–Хакен, 1976, компьютерное доказательство); гипотеза Хивуда для поверхностей. Жадная раскраска даёт ≤ Δ+1 (теорема Брукса — ≤ Δ, кроме K_n и нечётных циклов).
- **Оптимизационные задачи:** MST — Крускал O(E log E) с СНМ, Прим O(E log V) с кучей; кратчайшие пути — Дейкстра O(E log V) (неотрицательные веса), Форд–Беллман O(VE), Флойд–Уоршелл O(V³); максимальный поток — Форд–Фалкерсон, Эдмондс–Карп O(VE²), **теорема Форда–Фалкерсона о max-потоке и min-разрезе**; паросочетания — Куна, Хопкрофта–Карпа, теорема Кёнига.

## 1.6. Необходимые и достаточные условия в выпуклой негладкой задаче (теорема Куна–Таккера)

- **Задача:** f(x) → min, gᵢ(x) ≤ 0 (i=1..m), x ∈ X ⊆ ℝⁿ, f и gᵢ — **выпуклые**, вообще говоря негладкие; X выпукло.
- **Аппарат негладкого анализа:** субградиент c ∈ ∂f(x₀), если f(x) ≥ f(x₀) + ⟨c, x−x₀⟩ ∀x. Субдифференциал ∂f(x₀) — непустое выпуклое компактное множество во внутренних точках. Для дифференцируемой f: ∂f = {∇f}. Правило Моро–Рокафеллара: ∂(f+g) = ∂f + ∂g.
- **Функция Лагранжа:** L(x,λ) = f(x) + Σλᵢgᵢ(x), λ ≥ 0.
- **Условие регулярности Слейтера:** ∃x̄ ∈ X: gᵢ(x̄) < 0 для всех i. Без него теорема может нарушаться (нужен множитель λ₀ при f — форма Фрица Джона).
- **Теорема Куна–Таккера (выпуклый случай):** при условии Слейтера точка x* — решение ⟺ ∃λ* ≥ 0 такое, что (x*, λ*) — **седловая точка** L: L(x*,λ) ≤ L(x*,λ*) ≤ L(x,λ*) ∀x∈X, λ≥0. Эквивалентно: 0 ∈ ∂f(x*) + Σλᵢ*∂gᵢ(x*) + N_X(x*) и λᵢ*gᵢ(x*) = 0 (**условие дополняющей нежёсткости**).
- **Ключевой акцент:** в выпуклой задаче условия ККТ — не только необходимые, но и **достаточные**; в невыпуклой — только необходимые. Это и есть «изюминка» вопроса.
- Идея доказательства: теорема отделимости для выпуклых множеств (отделяем 0 от множества достижимых приращений) ⟹ существование опорной гиперплоскости ⟹ множители.
- Связь: λ* — решение двойственной задачи; отсутствие разрыва двойственности в выпуклом случае при Слейтере.

## 1.7. Необходимые условия оптимальности в форме принципа максимума Л. С. Понтрягина

- **Задача оптимального управления:** ẋ = f(x, u, t), x(t₀)=x₀, u(t) ∈ U (U — произвольное, в том числе замкнутое и невыпуклое множество), J = ∫_{t₀}^{t₁} f⁰(x,u,t)dt + Φ(x(t₁)) → min.
- Почему нужен именно принцип максимума: классическое вариационное исчисление требует внутренности точки минимума и гладкости по u; в реальных задачах управление ограничено (|u| ≤ 1), оптимум лежит на границе, вариации только односторонние.
- **Функция Гамильтона–Понтрягина:** H(ψ, x, u, t) = ⟨ψ, f(x,u,t)⟩ − ψ⁰f⁰(x,u,t), ψ⁰ ≥ 0.
- **Сопряжённая (кó-состояние) система:** ψ̇ = −∂H/∂x, с **условиями трансверсальности** на конце (например, ψ(t₁) = −∂Φ/∂x при свободном правом конце).
- **Теорема (принцип максимума):** если (x*, u*) оптимальны, то существует нетривиальная пара (ψ⁰, ψ(t)) ≠ 0 такая, что вдоль оптимальной траектории H(ψ, x*, u*, t) = max_{u∈U} H(ψ, x*, u, t) почти всюду; для автономной задачи H ≡ const (= 0 при свободном t₁).
- **Это необходимое условие**, не достаточное (достаточность — при выпуклости, теорема Мангасаряна; или через уравнение Беллмана).
- **Приложения:** задача о быстродействии, релейное (bang-bang) управление, теорема о числе переключений для линейных систем, особые режимы. Краевая задача для системы 2n уравнений — численно решается методом стрельбы.
- Связь с ДП: ψ(t) = −∂V/∂x, где V — функция Беллмана; принцип максимума — «характеристики» уравнения Гамильтона–Якоби–Беллмана.

## 1.8. Принцип наилучшего гарантированного результата. Минимакс. Оптимальные алгоритмы поиска экстремума

- **Постановка:** решение принимается в условиях неопределённости; выигрыш f(x, y), где x — наш выбор, y ∈ Y — неконтролируемый фактор (природа/противник). **Гарантированный результат:** максимин max_x min_y f(x,y) — гарантия «при худшем y»; минимакс min_y max_x f(x,y).
- Всегда max_x min_y f ≤ min_y max_x f. Равенство ⟺ существует **седловая точка**. Теорема фон Неймана о минимаксе: в смешанных стратегиях для матричной игры седловая точка есть всегда; сведение к паре двойственных ЗЛП.
- **Принцип Гермейера:** гарантирующая стратегия оптимальна для осторожного игрока; свёртка критериев в задачах многокритериальной оптимизации.
- **Оптимальные алгоритмы поиска экстремума** (гарантированная точность за N вычислений функции для унимодальной f на [a,b]):
  - деление отрезка пополам — сокращение в 2ⁿ, но по 2 вычисления на шаг;
  - **метод золотого сечения** — коэффициент сжатия τ = (√5−1)/2 ≈ 0.618, одно новое вычисление на итерацию;
  - **метод Фибоначчи** — доказано **оптимален** в минимаксном смысле при заранее заданном числе N вычислений; итоговая длина отрезка (b−a)/F_N;
  - для липшицевых функций — метод ломаных (Пиявского), оптимальный при известной константе L;
  - нижние оценки сложности: никакой алгоритм не может гарантировать лучше — это и есть содержание «оптимальности».
- Аргумент для комиссии: оптимальность алгоритма формулируется именно как **наилучший гарантированный результат** на классе задач — прямая связь с первой частью вопроса.

## 1.9. Метод штрафных функций в оптимизационных задачах

- **Идея:** заменить задачу с ограничениями f(x)→min, x∈D на последовательность задач без ограничений: Φ(x, r) = f(x) + r·P(x) → min по x ∈ ℝⁿ.
- **Внешний штраф:** P(x) = Σ max²(0, gᵢ(x)) + Σhⱼ²(x); P(x) = 0 на D, P > 0 вне. Итерации по r_k → ∞, точки x_k приближаются к D **снаружи** (допустимость только в пределе).
- **Внутренний штраф (барьерные функции):** B(x) = −Σ 1/gᵢ(x) или −Σ ln(−gᵢ(x)); Φ = f + (1/r)B, точки остаются **строго внутри** D; требуется непустая внутренность (условие Слейтера). Основа методов внутренней точки.
- **Теорема о сходимости:** при r_k → ∞ и непрерывности f, gᵢ любая предельная точка последовательности {x_k} — решение исходной задачи; f(x_k) монотонно приближается к f*.
- **Главная проблема — обусловленность:** при r → ∞ матрица Гессе Φ становится плохо обусловленной, «овражный» рельеф, ньютоновские шаги вырождаются. Отсюда — рекомендация умеренного роста r и «тёплого старта» (x_{k+1} стартует с x_k).
- **Точные штрафы:** P(x) = Σmax(0, gᵢ(x)) (негладкий, ℓ₁): решение достигается при **конечном** r > ‖λ*‖_∞, но целевая функция негладкая.
- **Метод множителей (расширенный лагранжиан, Хестенс–Пауэлл):** Φ = f + Σλᵢgᵢ + r/2·Σgᵢ² — сходится без r→∞, лишён проблемы обусловленности. Хороший «бонусный» пункт в ответе.

## 1.10. Динамическое программирование. Принцип оптимальности Р. Беллмана

- **Область применимости:** многошаговые (N-этапные) процессы принятия решений; свойство **отсутствия последействия** (марковость) и **оптимальной подструктуры**.
- **Принцип оптимальности Беллмана:** оптимальная стратегия обладает тем свойством, что каково бы ни было начальное состояние и начальное решение, оставшиеся решения должны составлять оптимальную стратегию относительно состояния, возникшего после первого решения.
- **Функциональное уравнение Беллмана:** V_k(s) = max_u {r(s,u) + V_{k+1}(f(s,u))}, V_N(s) = терминальная выплата. Непрерывный аналог — уравнение Гамильтона–Якоби–Беллмана: ∂V/∂t + max_u H(x, ∂V/∂x, u, t) = 0.
- **Необходимость и достаточность.** Необходимость: если стратегия оптимальна, её «хвост» оптимален (доказательство от противного — заменив хвост на лучший, улучшим целое). Достаточность: если функция V удовлетворяет уравнению Беллмана и краевому условию, то порождённая ею стратегия оптимальна (verification theorem). Обязательно обозначить обе стороны — вопрос сформулирован именно так.
- **Схема решения:** обратный ход (от последнего этапа к первому) — вычисление условно-оптимальных выигрышей; прямой ход — восстановление оптимальной траектории.
- **Примеры:** задача о ранце, кратчайший путь (Флойд, Беллман–Форд), распределение ресурсов, задача о замене оборудования, выравнивание последовательностей.
- **Проклятие размерности** Беллмана: трудоёмкость растёт экспоненциально с размерностью вектора состояния — главное ограничение метода; отсюда аппроксимативное ДП, RL.

## 1.11. Модели обучения, игр и поведения. Персептрон как динамическая система. Автоматные и марковские модели

- **Персептрон Розенблатта:** y = sign(⟨w, x⟩ − θ). Правило обучения (Хебба/дельта-правило): w_{k+1} = w_k + η·y_k·x_k при ошибке — это **разностное уравнение**, то есть дискретная динамическая система в пространстве весов; обучение = сходимость траектории к неподвижной точке/области решений.
- **Теорема Новикова о сходимости персептрона:** если выборка линейно разделима с зазором γ и ‖x‖ ≤ R, персептрон делает не более (R/γ)² ошибок — сходимость за конечное число шагов независимо от порядка предъявления.
- **Ограничения:** проблема XOR (Минский–Пейперт), линейная неразделимость ⟹ многослойные сети, обратное распространение ошибки, теорема Цыбенко об универсальной аппроксимации.
- **Автоматные модели поведения (автоматы Цетлина):** конечный автомат с памятью глубины d в случайной среде; штраф/поощрение меняет внутреннее состояние. **Результат:** автомат с достаточной глубиной памяти асимптотически оптимален (целесообразное поведение) — среднее число штрафов стремится к минимально возможному. Коллективное поведение автоматов, игры автоматов.
- **Марковские модели:** цепь Маркова (состояния, матрица переходов), эргодичность, стационарное распределение; **марковский процесс принятия решений (MDP)** = состояния + действия + вероятности переходов + награды; решается ДП (итерация по значениям/по стратегиям, уравнение Беллмана) — прямая связь с вопросом 1.10.
- **Игровые модели:** матричные игры, равновесие Нэша, смешанные стратегии, повторяющиеся игры, обучение в играх (fictitious play), эволюционная теория игр (репликаторная динамика — снова динамическая система).

# Раздел 2. Численные методы и методы оптимизации

## 2.1. Интерполяция и аппроксимация. Полиномы, МНК, сплайны, наилучшие приближения

- **Постановка интерполяции:** по узлам x₀<…<x_n и значениям f(xᵢ) построить P(x) с P(xᵢ)=f(xᵢ). Теорема: интерполяционный полином степени ≤ n существует и **единственен** (определитель Вандермонда ≠ 0).
- **Формы:** Лагранжа P(x)=Σf(xᵢ)lᵢ(x); Ньютона с разделёнными разностями (удобна при добавлении узла).
- **Погрешность:** f(x) − P_n(x) = f^{(n+1)}(ξ)/(n+1)! · ω_{n+1}(x), ω = Π(x−xᵢ). Минимизация max|ω| ⟹ **чебышёвские узлы** xᵢ = cos((2i+1)π/(2n+2)), max|ω| = 2^{−n}.
- **Феномен Рунге:** для f = 1/(1+25x²) на равномерной сетке P_n расходится при n→∞ ⟹ повышать степень нельзя, надо дробить (кусочная интерполяция).
- **Сплайн-интерполяция:** кубический сплайн дефекта 1 — на каждом отрезке кубика, C² на всём отрезке; сводится к трёхдиагональной СЛАУ (метод прогонки), **устойчив**, погрешность O(h⁴), для производной O(h³). Естественные/зажатые краевые условия. Экстремальное свойство: минимизирует ∫(S″)² — «физический» сплайн (минимум энергии изгиба).
- **МНК (аппроксимация):** m точек, полином степени n < m−1; минимизируем Σ(P(xᵢ)−fᵢ)²; **нормальные уравнения** AᵀA·c = Aᵀf; плохо обусловлены — на практике QR-разложение или SVD; ортогональные полиномы (Форсайта) дают диагональную систему.
- **Наилучшее равномерное приближение (чебышёвское):** min max|f−P|. **Теорема Чебышёва об альтернансе:** P* — полином наилучшего равномерного приближения степени ≤ n ⟺ существует альтернанс из n+2 точек, где f−P* достигает max по модулю с чередованием знаков. Существование и единственность. Алгоритм Ремеза. Теорема Вейерштрасса о плотности полиномов в C[a,b].
- **Наилучшее приближение в гильбертовом пространстве:** минимум ‖f−g‖ по подпространству H_n достигается на **ортогональной проекции**; критерий — ортогональность невязки подпространству; коэффициенты = коэффициенты Фурье по ортонормированному базису; неравенство Бесселя, равенство Парсеваля, минимальность существует и единственна (выпуклость и полнота). Ортогональные полиномы: Лежандра, Чебышёва, Эрмита, Лагерра.

## 2.2. Численное дифференцирование

- **Задача:** приблизить f′(x), f″(x) по значениям f в узлах. Основной приём: продифференцировать интерполяционный полином (или разложение Тейлора / метод неопределённых коэффициентов).
- **Базовые формулы:** правая разность (f(x+h)−f(x))/h — O(h); центральная (f(x+h)−f(x−h))/(2h) — **O(h²)**; вторая производная (f(x+h)−2f(x)+f(x−h))/h² — O(h²).
- **Методы построения:** (1) дифференцирование интерполяционного полинома Лагранжа/Ньютона; (2) разложение Тейлора и подбор коэффициентов так, чтобы обнулить максимальное число членов; (3) метод неопределённых коэффициентов на заданном шаблоне; (4) экстраполяция Ричардсона для повышения порядка.
- **Общая погрешность = погрешность аппроксимации (метода) + вычислительная (округления):**
  R(h) ≈ C·h^k + ε/h^m, где ε — уровень ошибки представления f.
  Для центральной разности: R(h) ≈ M₃h²/6 + ε/h. Минимум при **h_opt ≈ (3ε/M₃)^{1/3}**, минимальная достижимая погрешность ~ ε^{2/3}. Для f″: h_opt ~ ε^{1/4}, погрешность ~ √ε.
- **Ключевой вывод для аргументации:** уменьшать h бесконечно нельзя — численное дифференцирование **некорректно поставленная задача** (малое возмущение f даёт сколь угодно большое возмущение f′). Отсюда — методы регуляризации (Тихонов), сглаживание сплайнами/МНК перед дифференцированием.
- Дифференцирование на неравномерной сетке, погрешность на границах шаблона, односторонние формулы повышенного порядка.

## 2.3. Численное интегрирование

- **Квадратурная формула:** ∫_a^b p(x)f(x)dx ≈ Σ Aᵢ f(xᵢ). **Интерполяционного типа** — если получена интегрированием интерполяционного полинома; критерий: формула с n+1 узлом точна для полиномов степени ≤ n ⟺ она интерполяционного типа.
- **Формулы Ньютона–Котеса** — равноотстоящие узлы: трапеций (n=1), Симпсона (n=2), «3/8» (n=3), Буля. При n ≥ 8 появляются отрицательные веса ⟹ неустойчивость, высокие Ньютон–Котес не применяют.
- **Погрешности (на отрезке):** трапеции −(b−a)³f″(ξ)/12; Симпсона −(b−a)⁵f⁽⁴⁾(ξ)/2880 (точна для кубик — «бесплатный» порядок за счёт симметрии).
- **Составные формулы (на сетке из N отрезков):** трапеций R = −(b−a)h²f″(ξ)/12 = **O(h²)**; Симпсона R = −(b−a)h⁴f⁽⁴⁾(ξ)/180 = **O(h⁴)**; средних прямоугольников O(h²) с константой вдвое лучше трапеций.
- **Теорема об оценке погрешности и её порядке:** формулировать как «если f ∈ C^{k}[a,b], то |R| ≤ C·M_k·h^k», подчеркнуть, что порядок держится только при нужной гладкости; для негладких f порядок падает.
- **Правило Рунге** практической оценки: R_h ≈ (I_h − I_{h/2})/(2^p − 1); экстраполяция Ричардсона, метод Ромберга (таблица, порядок растёт до O(h^{2m})).
- **Квадратурные формулы наивысшей алгебраической точности (Гаусса):** узлы **тоже** свободные параметры ⟹ 2n+2 параметра ⟹ точность для полиномов степени **2n+1**. **Теорема:** формула с n+1 узлом имеет АСТ = 2n+1 ⟺ узлы — корни полинома степени n+1, ортогонального с весом p(x) ко всем полиномам меньшей степени (Лежандра при p≡1). Все веса Aᵢ > 0 ⟹ устойчивость; сходимость для любой непрерывной f. Гаусс–Чебышёв, Гаусс–Лагерр (несобственные интегралы), формулы Гаусса–Кронрода и Лобатто.
- Адаптивные квадратуры; кратные интегралы и метод Монте-Карло (погрешность O(N^{−1/2}) независимо от размерности — обосновать, почему в больших размерностях он побеждает).

## 2.4. Итерационные методы линейной алгебры

- **Мотивация:** для больших разреженных систем прямые методы (Гаусс O(n³)) разрушают разреженность (fill-in) и дороги.
- **Общая форма:** x^{k+1} = Bx^k + g (одношаговый стационарный метод), или каноническая форма Самарского: B(x^{k+1}−x^k)/τ_{k+1} + Ax^k = f.
- **Теорема о сходимости (основная):** метод сходится при любом x⁰ ⟺ **спектральный радиус ρ(B) < 1**; достаточное условие — ‖B‖ < 1 в какой-либо норме; скорость линейная, множитель ρ(B).
- **Медленные методы:** Якоби (x^{k+1} = D^{−1}((D−A)x^k + f)), Зейделя, простая итерация. Сходимость гарантирована при диагональном преобладании; для симметричной положительно определённой A метод Зейделя сходится всегда. Число итераций ~ O(1/h²) для сеточных задач — очень медленно.
- **Быстрые методы:** верхняя релаксация SOR с оптимальным ω (O(1/h) итераций), чебышёвское ускорение (набор оптимальных параметров τ_k по корням полинома Чебышёва), попеременно-треугольный метод Самарского, многосеточные методы (O(N) операций — оптимальны), предобусловливание (ILU, неполное разложение Холецкого).
- **Обусловленность:** cond(A) = ‖A‖·‖A^{−1}‖ = λ_max/λ_min для симметричной. Оценка: относительная погрешность решения ≤ cond(A)·(относительная погрешность данных). Плохая обусловленность ⟹ и прямые, и итерационные методы теряют точность/сходятся медленно. Для разностной задачи Дирихле cond ~ h^{−2}.
- **Вариационный подход:** для симметричной положительно определённой A решение Ax=f ⟺ минимум функционала F(x) = ½⟨Ax,x⟩ − ⟨f,x⟩. Отсюда — метод скорейшего спуска (оценка ((κ−1)/(κ+1))^k) и **метод сопряжённых градиентов**: сходится за ≤ n шагов точно, оценка 2((√κ−1)/(√κ+1))^k — квадратичное улучшение по κ. Обобщения на несимметричные: GMRES, BiCGStab. Вариационная постановка также даёт метод Ритца — мост к вопросу 2.9.

## 2.5. Численные методы задачи Коши для ОДУ. Рунге–Кутта, жёсткие системы, многошаговые методы

- **Задача:** y′ = f(x,y), y(x₀)=y₀. Теорема Пикара о существовании и единственности (липшицевость по y) — условие корректности, без которого численные методы бессмысленны.
- **Понятия:** сетка, шаг h; **локальная (на шаге) погрешность аппроксимации** и **глобальная погрешность**; метод имеет порядок p, если глобальная погрешность O(h^p) (локальная — O(h^{p+1})). Явные/неявные, одношаговые/многошаговые.
- **Методы Рунге–Кутта:** y_{n+1} = y_n + h·Σbᵢkᵢ, kᵢ = f(x_n + cᵢh, y_n + hΣaᵢⱼkⱼ). Таблица Бутчера. Эйлер (p=1), Хойн/модифицированный Эйлер (p=2), **классический РК4** (p=4, 4 вычисления f). Барьер Бутчера: при s ≥ 5 порядок < s. Условия порядка выводятся сопоставлением рядов Тейлора.
- **Контроль шага:** правило Рунге (двойной пересчёт), вложенные методы Рунге–Кутта–Фельберга RKF45, Дормана–Принса (основа ode45).
- **Жёсткие системы:** решение содержит компоненты с сильно различающимися масштабами затухания; формально λ_max/λ_min ≫ 1 при Re λ < 0. Проблема: явные методы вынуждены брать h по **самой быстрой** (уже затухшей) компоненте по соображениям устойчивости, а не точности.
- **Абсолютная устойчивость:** тестовое уравнение y′ = λy, область устойчивости на комплексной плоскости hλ. **A-устойчивость** — область содержит всю левую полуплоскость. **Барьеры Далквиста:** явных A-устойчивых методов нет; A-устойчивый многошаговый метод имеет порядок ≤ 2 (максимум — трапеций/Кранка–Николсон). Отсюда неявные методы: неявный Эйлер, трапеций, **методы Гира (BDF)** — жёстко устойчивы до порядка 6, неявные РК (Радо, Гаусса), L-устойчивость. На каждом шаге — решение нелинейной системы методом Ньютона.
- **Многошаговые (линейные m-шаговые) методы:** Σαⱼy_{n+j} = hΣβⱼf_{n+j}. **Адамса–Башфорта** (явные, интерполяция f по прошлым точкам), **Адамса–Мултона** (неявные), схемы «предиктор–корректор». Построение — методом неопределённых коэффициентов / интегрированием интерполяционного полинома.
- **Анализ:** первый и второй характеристические полиномы ρ(ζ), σ(ζ); **корневое условие (нуль-устойчивость)**: все корни ρ(ζ) по модулю ≤ 1, кратные — строго < 1. **Теорема Далквиста (эквивалентности):** сходимость ⟺ аппроксимация (согласованность) + устойчивость. Первый барьер Далквиста: порядок устойчивого m-шагового метода ≤ m+1 (m нечётно), ≤ m+2 (m чётно).
- Сравнение: многошаговые дешевле по числу вычислений f, но требуют разгона и хуже переносят смену шага.

## 2.6. Основные понятия теории разностных схем: аппроксимация, устойчивость, сходимость

- Излагать на канонической модели: **краевая задача для ОДУ 2-го порядка** −(k(x)u′)′ + q(x)u = f(x), u(0)=u(1)=0, k ≥ k₀ > 0, q ≥ 0.
- **Схема:** сетка ω_h с шагом h, разностный оператор: −(a y_x̄)_x + d y = φ, y₀ = y_N = 0. Операторная запись: L_h y_h = f_h.
- **Аппроксимация:** невязка ψ_h = L_h[u]_h − f_h (подставляем точное решение в схему). Схема аппроксимирует задачу с порядком m, если ‖ψ_h‖ = O(h^m). Проверяется разложением по Тейлору. Для указанной схемы m = 2 (при достаточной гладкости), при консервативной (интегро-интерполяционной) аппроксимации коэффициентов — 2 и для разрывных k.
- **Устойчивость:** ‖y_h‖ ≤ C‖f_h‖ с C, **не зависящей от h** — непрерывная и равномерная по h зависимость решения от правой части; эквивалентно ‖L_h^{−1}‖ ≤ C. Обосновывается через принцип максимума, энергетические неравенства (разностные аналоги неравенства Фридрихса), оценки собственных значений.
- **Сходимость:** z_h = y_h − [u]_h → 0 при h→0, порядок = порядок ‖z_h‖.
- **Основная теорема (Лакса / Филиппова–Рябенького):** **аппроксимация + устойчивость ⟹ сходимость**, причём с порядком аппроксимации. Доказательство в одну строчку: L_h z_h = −ψ_h ⟹ ‖z_h‖ ≤ C‖ψ_h‖. Это ядро ответа — комиссия ждёт именно эту связку.
- Обязательно контрпример: схема аппроксимирует, но неустойчива ⟹ не сходится (счёт «разваливается»).
- Дополнительно: консервативность (разностные аналоги законов сохранения), монотонность схемы, метод прогонки для трёхдиагональной системы и **условие устойчивости прогонки** (диагональное преобладание |bᵢ| ≥ |aᵢ|+|cᵢ|).

## 2.7. Численные методы многомерных краевых задач (задача Дирихле для уравнения Пуассона)

- **Задача:** Δu = −f в Ω, u|_Γ = μ. Прямоугольная сетка h₁, h₂; **пятиточечная схема «крест»**: Λy = (y_{i−1,j} − 2y_{ij} + y_{i+1,j})/h₁² + (y_{i,j−1} − 2y_{ij} + y_{i,j+1})/h₂² = −φ_ij. Аппроксимация **O(h₁²+h₂²)**; схема «ящик»/девятиточечная — O(h⁴).
- **Принцип максимума для разностных схем.** Схема канонического вида: A(P)y(P) = Σ_{Q∈Ш′(P)} B(P,Q)y(Q) + F(P), с условиями A > 0, B > 0, D(P) = A − ΣB ≥ 0. **Теорема:** если Λy ≥ 0 (F ≤ 0), то y не может достигать положительного максимума во внутренних узлах — максимум на границе. Пятиточечная схема этим условиям удовлетворяет.
- **Следствия — оценки и сходимость:** теорема сравнения (принцип мажоранты): подбирая мажорантную функцию (например, Y = (x² + y²)/4), получаем априорную оценку ‖y‖_C ≤ ‖μ‖_Γ + M·‖F‖_C ⟹ **устойчивость в равномерной норме**. Затем стандартно: z = y − u, Λz = −ψ, ‖z‖_C ≤ M‖ψ‖_C = O(h²) ⟹ **сходимость с порядком 2 в C**.
- **Специфика численного решения:** матрица системы — блочно-трёхдиагональная, разреженная, но огромная (N = n² неизвестных), cond ~ h^{−2}. Гаусс неприменим (fill-in, O(N³)). Методы:
  - прямые быстрые: метод разделения переменных с БПФ O(N log N), метод циклической редукции;
  - итерационные: Якоби/Зейдель (медленно, O(h^{−2}) итераций), SOR с оптимальным ω, попеременно-треугольный метод, чебышёвское ускорение;
  - **методы переменных направлений (ADI)**, экономичные схемы Писмена–Рэкфорда, метод суммарной аппроксимации Самарского;
  - **многосеточный метод** — асимптотически оптимален, O(N);
  - МСГ с предобусловливанием.
- Криволинейная граница: аппроксимация граничных условий (снос, интерполяция), потеря порядка на границе; альтернатива — МКЭ на треугольной сетке.

## 2.8. Численные методы нестационарных задач (уравнение теплопроводности). Метод разделения переменных для разностных схем

- **Задача:** ∂u/∂t = ∂²u/∂x² + f, u(x,0)=u₀(x), краевые условия. Сетка по x (h) и по t (τ).
- **Схема с весами (σ-схема):** (y^{n+1}−y^n)/τ = σΛy^{n+1} + (1−σ)Λy^n + φ.
  - σ = 0 — **явная схема**, аппроксимация O(τ + h²), решение по формуле, но условно устойчива;
  - σ = 1 — **чисто неявная**, O(τ + h²), безусловно устойчива, на каждом слое — прогонка;
  - σ = ½ — **Кранка–Николсон**, O(τ² + h²), безусловно устойчива (но не L-устойчива: осцилляции на негладких данных);
  - σ = ½ − h²/(12τ) — схема повышенного порядка O(τ² + h⁴).
- **Метод разделения переменных для разностных схем (спектральный признак устойчивости, фон Нейман):** ищем частные решения вида y_j^n = q^n·e^{iφj} (разностные гармоники). Подстановка даёт **множитель перехода** q(φ) = (1 − 4(1−σ)γ sin²(φ/2)) / (1 + 4σγ sin²(φ/2)), где γ = τ/h².
  Условие устойчивости: |q(φ)| ≤ 1 для всех φ.
  - при σ ≥ ½ — выполняется всегда ⟹ **безусловная устойчивость**;
  - при σ < ½ — условие τ ≤ h²/(2(1−2σ)); для явной схемы (σ=0) знаменитое **τ ≤ h²/2**.
- **Проблема вычислительной устойчивости:** это и есть главный практический вывод — для явной схемы измельчение сетки вдвое требует уменьшения шага по времени вчетверо ⟹ рост трудоёмкости в 8 раз ⟹ на практике для параболических задач берут неявные схемы. При нарушении условия — «разболтка», экспоненциальный рост высокочастотных гармоник.
- **Обоснование сходимости:** аппроксимация + устойчивость (спектрально или энергетически, в сеточной норме L₂) ⟹ сходимость с порядком O(τ^k + h²), теорема Лакса. Строгая устойчивость по начальным данным и правой части — теоремы Самарского об устойчивости схем с весами в энергетических нормах (условие σ ≥ ½ − 1/(τ‖Λ‖)).
- Многомерный случай: явная схема даёт τ ≤ h²/4 (для 2D), неявная — уже не трёхдиагональная система ⟹ **экономичные схемы**: продольно-поперечная (ADI), локально-одномерная схема Самарского, метод дробных шагов Яненко.

## 2.9. Основные подходы к решению краевых задач: интегрально-интерполяционный метод, Бубнов–Галёркин, МКЭ, Ритц

- Классификация подходов: (1) конечно-разностные, (2) проекционные (Галёркин, Ритц, коллокация, МНК), (3) проекционно-сеточные (МКЭ), (4) интегральных уравнений (метод граничных элементов).
- Модель: −(k u′)′ + qu = f, u(0)=u(1)=0.
- **Интегрально-интерполяционный метод (метод баланса, Тихонов–Самарский):** интегрируем уравнение по контрольному объёму [x_{i−1/2}, x_{i+1/2}] — получаем точное уравнение баланса потоков w = −k u′: w_{i−1/2} − w_{i+1/2} + ∫qu = ∫f. Затем интерполируем: поток аппроксимируем через среднее гармоническое aᵢ = [1/h∫dx/k]^{−1}. Результат — **консервативная** схема, сохраняющая баланс, работающая при **разрывных** коэффициентах, порядок 2. Главное преимущество перед формальным разложением Тейлора — именно консервативность.
- **Метод Бубнова–Галёркина:** ищем u_n = Σcⱼφⱼ по базисным функциям, удовлетворяющим краевым условиям; требуем **ортогональности невязки** пробным функциям: (L u_n − f, ψᵢ) = 0. У Бубнова–Галёркина ψᵢ = φᵢ (пробные = базисные); если ψ ≠ φ — метод Петрова–Галёркина. Получаем СЛАУ. Слабая (вариационная) постановка: a(u,v) = (f,v) ∀v ∈ H₀¹; лемма Лакса–Мильграма (существование, единственность, устойчивость), лемма Сеа (квазиоптимальность приближения).
- **Метод Ритца:** применим, когда оператор **симметричен и положительно определён**; тогда решение ⟺ минимум функционала энергии J(u) = ½a(u,u) − (f,u). Минимизируем J по подпространству span{φᵢ} — приходим к **той же** СЛАУ, что у Галёркина (для симметричных задач методы совпадают). Матрица симметрична и положительно определена. Для несимметричных задач Ритц неприменим, Галёркин — да.
- **МКЭ:** = Галёркин/Ритц с **финитным** базисом. Разбиение области на элементы, локальные базисные функции с малым носителем (кусочно-линейные «шапочки», квадратичные, эрмитовы). Следствия: матрица жёсткости разрежённая и ленточная; легко обрабатываются сложные геометрии и неоднородности; локальное сгущение сетки, h- и p-версии. Сборка локальных матриц. Оценка погрешности ‖u−u_h‖_{H¹} ≤ Ch^p|u|_{H^{p+1}} (лемма Сеа + интерполяционные оценки Брамбла–Гильберта). Метод коллокаций — требуем обращения невязки в нуль в узлах; метод наименьших квадратов — минимизируем ‖Lu_n−f‖².
- Сравнение: разностные схемы проще и быстрее на регулярных сетках; МКЭ выигрывает на сложной геометрии и даёт естественную обработку краевых условий Неймана (естественные краевые условия).

## 2.10. Численные методы решения нелинейных уравнений и систем

- **Задача:** f(x)=0 или F(x)=0, F: ℝⁿ→ℝⁿ. Все методы итерационные; вопросы: локализация корня, сходимость, порядок сходимости, критерий остановки.
- **Отделение корней** (табулирование, теорема Больцано о смене знака), затем уточнение.
- **Метод половинного деления:** гарантированная сходимость при f(a)f(b)<0, линейная, множитель ½, n шагов ⟹ точность (b−a)/2ⁿ. Не обобщается на системы.
- **Метод простой итерации:** x = φ(x), x_{k+1} = φ(x_k). **Принцип сжимающих отображений (Банаха):** если φ: [a,b]→[a,b] и |φ′| ≤ q < 1, то единственная неподвижная точка и сходимость при любом x₀, |x_k − x*| ≤ q^k/(1−q)·|x₁−x₀| — линейная сходимость. Для систем: ‖φ′‖ ≤ q < 1 (норма матрицы Якоби).
- **Метод Ньютона (касательных):** x_{k+1} = x_k − f(x_k)/f′(x_k); для систем x_{k+1} = x_k − J⁻¹(x_k)F(x_k), практически — решение СЛАУ J·Δx = −F. **Квадратичная сходимость** при простом корне, f ∈ C², достаточно хорошем начальном приближении. Условия сходимости: **теорема Канторовича** (условия на ‖J⁻¹(x₀)‖, ‖F(x₀)‖, константу Липшица J и их комбинацию h ≤ ½ — гарантируют существование корня и сходимость). Достаточное условие монотонной сходимости: f′f″ ≠ 0 и f(x₀)f″(x₀) > 0.
- **Проблемы Ньютона и их лечение:** зависимость от x₀ (глобализация — демпфированный Ньютон с параметром релаксации, метод продолжения по параметру/гомотопии, линейный поиск), дороговизна J (модифицированный Ньютон — J фиксирована, линейная сходимость; квази-ньютоновские методы Бройдена, Шермана–Моррисона; неточный Ньютон — СЛАУ решается итерационно, Newton–Krylov), кратные корни (порядок падает до линейного; лечится x_{k+1} = x_k − m·f/f′).
- **Метод секущих:** производная заменена разделённой разностью, порядок сходимости золотое сечение ≈ 1.618, но без вычисления f′ — по «затратам» часто выгоднее Ньютона. Метод хорд (линейный), метод Стеффенсена (квадратичный без производной), метод Брента (комбинация надёжности бисекции и скорости обратной квадратичной интерполяции) — де-факто стандарт в библиотеках.
- **Критерии остановки:** |x_{k+1}−x_k| < ε, |f(x_k)| < δ, обязательно и то и другое (плохо обусловленные корни); ограничение числа итераций.
- Связь с оптимизацией: F(x) = ∇f(x) = 0 ⟹ метод Ньютона в оптимизации, гессиан вместо якобиана, модификации при неположительной определённости (Левенберг–Марквардт, доверительная область).

# Раздел 3. Структуры и алгоритмы обработки данных и знаний

## 3.1. Понятие алгоритма. Способы записи. Основные конструкции. Эффективность

- **Алгоритм** — конечная последовательность точно определённых действий, приводящая от исходных данных к результату. **Свойства:** дискретность, детерминированность, результативность (конечность), массовость, понятность/элементарность шагов.
- **Формализации:** машина Тьюринга, нормальные алгорифмы Маркова, рекурсивные функции, λ-исчисление. **Тезис Чёрча–Тьюринга** об их эквивалентности. Алгоритмически неразрешимые задачи (проблема остановки) — важно упомянуть для «научности» ответа.
- **Способы записи:** словесный, блок-схема (ГОСТ 19.701-90), псевдокод, язык программирования, схемы алгоритмов, диаграммы Насси–Шнейдермана.
- **Базовые конструкции** (теорема Бёма–Якопини — любой алгоритм выразим через три): следование, ветвление, цикл (с предусловием, с постусловием, с параметром). Плюс подпрограмма/рекурсия. Основа структурного программирования.
- **Эффективность:** временная и ёмкостная сложность. Асимптотические обозначения O, Ω, Θ, o. Худший / средний / лучший случай, амортизированная сложность. Классы: O(1), O(log n), O(n), O(n log n), O(n²), O(2ⁿ), O(n!). Классы сложности P, NP, NP-полнота, сведение задач.
- Компромисс «время–память»; учёт констант и кеш-локальности на практике.

## 3.2. Понятие структуры данных. Абстрактные типы данных. Массивы

- **Структура данных** — способ организации данных в памяти вместе с набором операций. **АТД** — спецификация: множество значений + операции + их семантика, **без** указания реализации (инкапсуляция, разделение интерфейса и реализации). Примеры АТД: список, стек, очередь, множество, словарь, приоритетная очередь, граф.
- Один АТД — много реализаций с разной сложностью (словарь: хеш-таблица O(1) в среднем vs сбалансированное дерево O(log n) с упорядоченностью).
- **Массив:** конечная последовательность однотипных элементов, размещённых в непрерывной области памяти. Адресация: addr(a[i]) = base + i·sizeof(T) ⟹ **доступ по индексу O(1)**. Вставка/удаление в середину O(n).
- Статические и динамические массивы; **динамический массив с удвоением ёмкости** — амортизированное O(1) на вставку в конец (доказательство методом «бухгалтерского учёта»/потенциалов). Многомерные массивы: построчное (row-major, C) и постолбцовое (column-major, Fortran) размещение — влияет на кеш-производительность.
- Сравнение массив ↔ связный список: доступ O(1) vs O(n); вставка O(n) vs O(1) при известной позиции; память: непрерывность и кеш vs накладные расходы на указатели.

## 3.3. Однопроходные алгоритмы работы с массивами

- **Определение:** алгоритм, просматривающий каждый элемент **ровно один раз**, за O(n) времени и, как правило, O(1) дополнительной памяти. Актуальны для потоковых данных (streaming), когда массив не помещается в память.
- **Классика:** поиск минимума/максимума (и одновременно min и max за 3n/2 сравнений — попарная схема); сумма, среднее; подсчёт вхождений; проверка упорядоченности; **алгоритм Кадане** для максимальной суммы подмассива (ДП за один проход); скользящее среднее.
- **Однопроходные с накоплением инварианта:** алгоритм Бойера–Мура для мажоритарного элемента (кандидат + счётчик, O(1) памяти); онлайновое вычисление дисперсии (алгоритм Уэлфорда — численно устойчив, в отличие от формулы через сумму квадратов); резервуарная выборка (Reservoir sampling) для случайного элемента из потока неизвестной длины.
- **Двухуказательные приёмы за один проход:** удаление дубликатов из отсортированного массива in-place, перестановка по признаку (partition Хоара), разворот массива, схема сжатия (stable partition).
- Ключевая аргументация на экзамене: почему O(1) памяти и почему нельзя обойтись меньше, чем n просмотрами (нижняя оценка — нужно «увидеть» каждый элемент).

## 3.4. Алгоритмы поиска элемента в массиве

- **Линейный (последовательный) поиск:** O(n), не требует упорядоченности; в среднем n/2 сравнений при равновероятном наличии; приём «барьер» (sentinel) — убирает проверку выхода за границу, ускоряет константу.
- **Бинарный (двоичный) поиск:** требует **отсортированного** массива, O(log n). Корректность через инвариант цикла «искомый элемент лежит в [l, r]». Классическая ловушка переполнения mid = (l+r)/2 → l + (r−l)/2. Варианты: lower_bound / upper_bound (первый ≥ x, первый > x) — важнее самого «найти».
- **Нижняя оценка:** любой алгоритм поиска, основанный на сравнениях, требует Ω(log n) в худшем случае — дерево решений с n листьями имеет высоту ≥ log₂n. Это делает бинарный поиск **оптимальным**.
- **Интерполяционный поиск:** предполагает равномерное распределение, O(log log n) в среднем, но O(n) в худшем. **Экспоненциальный (галопирующий) поиск** — для неограниченных/бесконечных последовательностей, O(log i). **Троичный поиск** — для унимодальных функций (экстремум, а не значение).
- **Со структурами:** хеш-таблица — O(1) в среднем; сбалансированное дерево — O(log n) гарантированно + порядок; блочный поиск (Шеннона/jump search) O(√n).
- Выбор метода: одноразовый поиск в неотсортированном массиве — линейный (сортировать O(n log n) невыгодно); многократные поиски — окупается сортировка или построение индекса.

## 3.5. Основные структуры данных: списки, стек, очередь, дек

- **Связный список.** Однонаправленный: узел = {данные, next}, есть голова. Вставка/удаление после известного узла O(1), доступ по номеру O(n), поиск O(n). **Двунаправленный:** {prev, данные, next} — удаление узла по ссылке O(1), обход в обе стороны, цена — лишний указатель. Кольцевой список; фиктивный (dummy) узел упрощает граничные случаи. Классические задачи: разворот списка за O(n)/O(1), поиск цикла (алгоритм Флойда «черепаха и заяц»), слияние отсортированных, поиск середины двумя указателями.
- **Стек (LIFO):** push, pop, top, empty — все O(1). Реализация массивом (быстро, ограничение/удвоение) или списком (нет ограничения, накладные расходы). **Применения:** вычисление выражений в ОПЗ (обратная польская запись), алгоритм сортировочной станции Дейкстры, проверка баланса скобок, стек вызовов и раскрутка рекурсии, DFS без рекурсии, откат (undo).
- **Очередь (FIFO):** enqueue, dequeue — O(1). Реализация **кольцевым буфером** над массивом (обязательно проговорить: индексы по модулю, различение «пуста/полна») или списком с указателями на голову и хвост. Применения: BFS, буферизация, планировщики, очереди задач. Приоритетная очередь — отдельный АТД (куча, O(log n)).
- **Дек (двусторонняя очередь):** вставка/удаление с обоих концов O(1). Реализация: двунаправленный список или массив блоков; служит основой для стека и очереди одновременно. Применение: скользящий максимум за O(n) (монотонный дек), алгоритм 0-1 BFS.
- Сравнительная таблица сложностей — сильный ход в устном ответе.

## 3.6. Динамическое программирование. Жадные алгоритмы

- **ДП** применимо при: **оптимальной подструктуре** (оптимум задачи строится из оптимумов подзадач) + **перекрывающихся подзадачах** (иначе — «разделяй и властвуй»). Две реализации: нисходящая с мемоизацией (рекурсия + кеш) и восходящая (заполнение таблицы). Трудоёмкость ≈ (число состояний) × (стоимость перехода).
- **Классические задачи:** числа Фибоначчи (O(n) вместо O(φⁿ)), рюкзак O(nW), наибольшая общая подпоследовательность O(nm), редакционное расстояние Левенштейна, наибольшая возрастающая подпоследовательность (O(n²) ДП или O(n log n) с бинарным поиском), матричное умножение (расстановка скобок) O(n³), Флойд–Уоршелл, TSP Хелда–Карпа. Оптимизация памяти — хранить два слоя таблицы.
- **Жадный алгоритм:** на каждом шаге локально оптимальный выбор, без пересмотра. Условия корректности: оптимальная подструктура + **свойство жадного выбора** (существует оптимальное решение, содержащее жадный первый выбор). Стандартная схема доказательства — **обменный аргумент** (exchange argument) или индукция по «жадный не хуже».
- **Теоретическая база:** жадный алгоритм даёт оптимум для любой весовой функции ⟺ система независимости является **матроидом** (теорема Радо–Эдмондса). Пример: алгоритм Крускала — матроид графов.
- **Верные жадные:** Крускал и Прим (MST), Дейкстра, коды Хаффмана, дробный рюкзак, задача о выборе заявок (по времени окончания), размен монет в канонических системах.
- **Неверные жадные:** 0-1 рюкзак (обязательно привести контрпример!), размен монет в системе {1, 3, 4} для суммы 6 (жадно 4+1+1 = 3 монеты, оптимально 3+3 = 2), TSP «ближайший сосед».
- **Сравнение:** жадный быстрее (обычно O(n log n)) но требует доказательства; ДП надёжнее, но дороже по времени и памяти. Эта пара «жадный vs ДП» — ключевой смысловой стержень ответа.

## 3.7. Алгоритмы сортировки

- **Постановка:** упорядочить последовательность по ключу. Характеристики: временная сложность (худший/средний/лучший), память (in-place или нет), **устойчивость** (stable — сохраняет относительный порядок равных), адаптивность (быстрее на почти отсортированных), внутренняя/внешняя.
- **Квадратичные O(n²):** пузырьковая (устойчивая, лучший O(n) с флагом), выбором (неустойчивая, ровно n(n−1)/2 сравнений всегда, минимум обменов — n), вставками (устойчивая, **адаптивная**: O(n+k) при k инверсиях, лучший O(n); лучший выбор для малых и почти упорядоченных массивов, используется как «дно» гибридных сортировок). Шелла — вставки с убывающими промежутками, O(n^{3/2})…O(n log²n) в зависимости от последовательности шагов.
- **Быстрая сортировка (Хоара):** разделяй-и-властвуй, partition вокруг опорного. Среднее O(n log n), **худший O(n²)** (уже отсортированный массив при плохом выборе опорного), память O(log n) на стек рекурсии, неустойчива. Лечение худшего случая: случайный опорный, медиана трёх, introsort (переход на пирамидальную при глубокой рекурсии), трёхпутевое разбиение при дубликатах.
- **Сортировка слиянием:** гарантированные O(n log n), **устойчива**, требует O(n) дополнительной памяти; естественная база для **внешней сортировки** (многопутевое слияние больших файлов) и параллелизма.
- **Пирамидальная (heapsort):** построение кучи за O(n) + n извлечений ⟹ гарантированные O(n log n), **in-place**, неустойчива, плохая кеш-локальность.
- **Линейные (не на сравнениях):** подсчётом O(n+k) при ограниченном диапазоне ключей, поразрядная (LSD/MSD) O(d·n), карманная (bucket) O(n) в среднем при равномерном распределении. Требуют предположений о структуре ключей.
- **Гибриды на практике:** Introsort (std::sort), **Timsort** (Python, Java) — слияние + вставки, использует естественные упорядоченные серии (runs), устойчива, адаптивна.

## 3.8. Сравнение алгоритмов сортировки. Хеш-функция и хеш-таблица. Деревья, виды деревьев, обход дерева

*(в программе этот пункт склеен из двух тем — отвечать нужно обе части)*

**Часть А. Сравнение сортировок**
- Сводная таблица: имя / худший / средний / память / устойчивость / адаптивность.
- **Нижняя оценка Ω(n log n)** для сортировок сравнениями: дерево решений имеет n! листьев, высота ≥ log₂(n!) = Θ(n log n) (формула Стирлинга). ⟹ merge/heap/introsort асимптотически оптимальны, а линейные сортировки обходят границу только потому, что **не используют сравнения**.
- Критерии выбора: размер данных, стоимость сравнения vs обмена, наличие памяти, требуется ли устойчивость, степень предупорядоченности, внешняя память.

**Часть Б. Хеширование**
- **Хеш-функция** h: K → {0..m−1}. Требования: детерминированность, равномерность распределения, быстрое вычисление, лавинный эффект. Методы: деления (h = k mod m, m — простое), умножения (метод Кнута с золотым сечением), универсальное хеширование (случайный выбор из семейства — защита от «плохого» набора ключей).
- **Коллизии** (неизбежны по принципу Дирихле при |K| > m). Разрешение: **цепочками** (списки в ячейках; средняя сложность O(1+α), α = n/m — коэффициент заполнения) и **открытая адресация** (линейное/квадратичное пробирование, двойное хеширование; проблема кластеризации, удаление через «надгробия», требуется α < 1, рехеширование при α > 0.7).
- **Оценки:** поиск/вставка/удаление O(1) **в среднем**, O(n) в худшем (все ключи в одну ячейку). Нет порядка на ключах — нельзя выполнять запросы «следующий больший», в отличие от дерева.
- Применения: словари/множества, кеши, индексы БД, проверка целостности (криптографические хеши), фильтр Блума.

**Часть В. Деревья**
- **Дерево** — связный ациклический граф; корневое дерево: корень, потомки, предки, лист, высота, глубина. Двоичное дерево; полное, совершенное, сбалансированное.
- **Виды:** двоичное дерево поиска (BST: левое < корень < правое; поиск/вставка/удаление O(h), h = O(log n) в среднем и O(n) в вырожденном случае); **самобалансирующиеся** — АВЛ (баланс высот ≤ 1, строгая балансировка, быстрый поиск), красно-чёрное (слабее сбалансировано, дешевле вставки; std::map), декартово дерево (treap), splay; **B-дерево / B+дерево** (многопутевые, для внешней памяти и индексов БД — минимизируют число обращений к диску); **куча** (частично упорядоченное, для приоритетной очереди); **префиксное дерево (trie)**; дерево отрезков и дерево Фенвика для запросов на диапазонах; синтаксические деревья.
- **Обходы:** в глубину — прямой (pre-order: корень, левое, правое), симметричный (in-order: для BST даёт **отсортированную** последовательность), обратный (post-order: для удаления дерева/вычисления выражений); в ширину (level-order, через очередь). Рекурсивная и итеративная (через стек) реализации, обход Морриса за O(1) памяти. Все обходы O(n).

## 3.9. Программная реализация однопроходных алгоритмов работы с массивами

- Это **практический** вопрос: ждут код (на доске/устно) + обоснование корректности и сложности.
- Заготовки, которые надо уметь написать без запинки: min/max за один проход; сумма и среднее; подсчёт по условию; проверка отсортированности; **алгоритм Кадане**; удаление дубликатов in-place двумя указателями; сдвиг нулей в конец; мажоритарный элемент Бойера–Мура; Уэлфорд для дисперсии.
- **Что проговаривать при защите кода:** инвариант цикла (что верно до/после каждой итерации), обработка граничных случаев (пустой массив, один элемент, все элементы равны), корректность инициализации (min/max инициализировать **первым элементом**, а не нулём/константой — классическая ошибка), сложность O(n) времени и O(1) памяти, переполнение при суммировании (тип аккумулятора), численная устойчивость.
- Демонстрировать читаемый код: осмысленные имена, ранние возвраты, отсутствие «магических чисел», при необходимости — юнит-тесты на граничных случаях.

## 3.10. Программная реализация алгоритмов поиска элемента в массиве

- Уметь написать: линейный поиск (с барьером и без), **бинарный поиск** в итеративной и рекурсивной формах, lower_bound / upper_bound, поиск в отсортированном по частям массиве.
- **Критические детали, за которые ставят/снимают баллы:**
  - границы: полуинтервал [l, r) vs отрезок [l, r] — выбрать одну схему и не путать;
  - `mid = l + (r − l) / 2` — защита от переполнения;
  - условие завершения `while (l < r)` и корректный сдвиг (`l = mid + 1`, `r = mid`) — иначе бесконечный цикл;
  - инвариант: искомое, если оно есть, лежит в текущем диапазоне;
  - что возвращать при отсутствии элемента (индекс вставки vs −1).
- Обоснование: сложность O(log n), предусловие отсортированности, доказательство завершаемости (длина диапазона строго убывает), нижняя оценка Ω(log n).
- Обобщения: бинарный поиск **по ответу** (поиск минимального значения параметра, при котором предикат становится истинным) — сильный пример прикладного применения; поиск в матрице, отсортированной по строкам и столбцам, за O(n+m).

## 3.11. Программная реализация алгоритмов сортировки

- Уметь написать: сортировку вставками, выбором, пузырьком (с флагом), **слиянием** (рекурсия + функция merge), **быструю** (partition Хоара или Ломуто), при необходимости — heapsort (siftDown + построение кучи).
- **Детали реализации, которые проверяют:**
  - merge: работа с временным буфером, «хвосты» после исчерпания одной половины, устойчивость обеспечивается сравнением `<=` при выборе из левой части;
  - quicksort: выбор опорного (медиана трёх/случайный), корректность partition, рекурсия сначала в меньшую половину (ограничение стека O(log n)), переход на вставки при малых подмассивах;
  - обмен элементов, отсутствие лишних копирований, компаратор как параметр (обобщённость).
- **Обоснование:** рекуррентное соотношение T(n) = 2T(n/2) + O(n) ⟹ O(n log n) (основная теорема о рекуррентных соотношениях / master theorem); для quicksort — среднее по случайному опорному O(n log n), худшее O(n²).
- Тестирование: массивы отсортированные, обратно отсортированные, с дубликатами, все элементы равны, пустой, из одного элемента; проверка устойчивости на парах (ключ, порядковый номер).

## 3.12. Программная реализация жадных алгоритмов

*(в программе это п. 13 — нумерация в перечне сбита, пункт 12 отсутствует)*

- Уметь написать: задачу о выборе заявок (сортировка по времени окончания + один проход), дробный рюкзак (сортировка по vᵢ/wᵢ), размен монет (жадно + оговорка о неканонических системах), **алгоритм Хаффмана** (приоритетная очередь, построение дерева, O(n log n)), **Крускал** (сортировка рёбер + система непересекающихся множеств DSU со сжатием путей и рангами), **Прим** (куча), **Дейкстра** (куча).
- Общая структура жадного кода: (1) упорядочить/подготовить приоритет, (2) один проход с проверкой допустимости, (3) добавить в ответ. Отсюда типичная сложность O(n log n), где логарифм — цена сортировки или кучи.
- **Что нужно проговорить обязательно:** доказательство корректности обменным аргументом (например, для выбора заявок: «пусть оптимальное решение не содержит заявку с самым ранним окончанием; заменим — решение не ухудшится»), и **контрпример**, показывающий, что жадный подход не универсален (0-1 рюкзак, монеты {1,3,4}).
- Практические детали: DSU (find со сжатием путей, union by rank — почти O(1) амортизированно, обратная функция Аккермана), компаратор для сортировки структур, реализация приоритетной очереди.

**Формулы и константы, которые надо помнить точно:**
- Погрешность интерполяции: f^{(n+1)}(ξ)/(n+1)!·ω(x)

- Нижняя оценка сортировки Ω(n log n), поиска Ω(log n)
- ДП для рюкзака O(nW), Хелд–Карп O(n²2ⁿ), венгерский O(n³)

**Теоремы «одной строкой» (называть точно):** Кантора–Бернштейна, Поста, Куна–Таккера, принцип максимума Понтрягина, принцип оптимальности Беллмана, Эйлера (эйлеров цикл), Дирака/Оре, Понтрягина–Куратовского, Кэли, Форда–Фалкерсона, Чебышёва об альтернансе, Вейерштрасса, Далквиста (эквивалентности и барьеры), Лакса (аппроксимация + устойчивость = сходимость), принцип максимума для разностных схем, Банаха о сжимающих отображениях, Канторовича, Новикова о персептроне, Радо–Эдмондса о матроидах, Бёма–Якопини.
